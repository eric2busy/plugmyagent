What it does

WeatherAPI.com bundles a lot into one service: real-time weather, a 3-day forecast, government weather alerts, moon phase and sunrise times, plus the local time zone. The free tier is generous enough for most side projects. It also lets you look up weather by US ZIP code or IP address.

What you can do with it

  • Build a morning briefing with weather, sunrise time, and alerts in one call
  • Look up weather by ZIP code for a shipping or logistics form
  • Show the moon phase on an events calendar

Set it up

  1. 1. Sign up free on the signup page. No credit card needed.
  2. 2. Find your API key in the dashboard.
  3. 3. Try the interactive API Explorer to test requests without writing code.
  4. 4. Start with /v1/current.json for current weather or /v1/forecast.json for the 3-day forecast.

Example request

https://api.weatherapi.com/v1/current.json?key=YOUR_KEY&q=London
