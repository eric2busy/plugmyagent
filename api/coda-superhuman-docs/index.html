About

Coda, now rebranded as Superhuman Docs, is a collaborative document platform with an API v1 that is free of charge in both free and paid workspaces. The API covers docs, tables, rows, and formulas with API token authentication. The separate Admin API is Enterprise-only and not part of the free offering.

Details

Free to start. You may need a free key, but no credit card.

Auth: Free key (no card)

Rate limit: 100 read requests per 6 seconds and 10 write requests per 6 seconds per token

Verified: 2026-09-13

Best for: docs spreadsheets collaboration

Read the docs Back to catalog

Setup

  1. Sign up for a free Coda workspace
  2. Open account settings and generate an API token
  3. Send the token as an Authorization: Bearer header
  4. List your docs with GET /v1/docs
  5. Read and update tables with the rows endpoints
  6. Stay within the read and write throttle windows
Sign up
Example
GET https://coda.io/apis/v1/docs with header Authorization: Bearer YOUR_TOKEN

Use cases

  • Sync form responses into a collaborative doc table
  • Build a lightweight database app on doc tables
  • Automate doc generation from structured data
