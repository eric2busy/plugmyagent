TheMealDB

Free recipe and meal database with simple search.

Open in PlugMyAgentOfficial docs

What it does

TheMealDB is a free, crowdsourced database of meals and recipes with a dead-simple REST API. Search by name, filter by category, cuisine area, or ingredient, and get full recipes with images. The free V1 test key (1) works immediately with no signup.

What you can do with it

  • Add a recipe search feature to a cooking app
  • Generate meal ideas from ingredients you have on hand
  • Build a meal-of-the-day widget for a website

Set it up

  1. No signup is required to start. Use test key 1.
  2. Browse the documentation to see the search and filter endpoints.
  3. Call the endpoints with the key in the URL path.
  4. Upgrade to a paid key only if you need the premium endpoints.
  5. Add image support using the meal thumbnail URLs in responses.

Example request

https://www.themealdb.com/api/json/v1/1/search.php?s=chicken
