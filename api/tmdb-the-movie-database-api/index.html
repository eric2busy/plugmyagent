TMDB (The Movie Database) API

The world's most popular community-built database of movies, TV shows, and actors, with a full developer API.

What it does

TMDB is like a giant encyclopedia of movies and TV, kept up to date by movie fans around the world. It hands you posters, cast lists, ratings, trailers, release dates, and even where to stream something right now. Practically every movie app you've ever used gets its data from somewhere like this.

What you can do with it

  • A small cinema or film club builds a 'what's showing this week' page with real posters and trailers automatically
  • A blogger adds rich movie cards (cast, ratings, artwork) to their review posts without copying anything by hand
  • A small business runs a date-night recommendation widget that suggests movies by genre and mood

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for TMDB (The Movie Database) API ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Create a free account at themoviedb.org/signup
  2. Go to Settings, then the API section, and request an API key
  3. Choose the free developer option and describe your project in a sentence
  4. Copy your API key and paste it into your requests as ?api_key=YOUR_KEY
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.

Mine: PASTE_KEY_HERE. Put it where the example above shows (usually an Authorization header or a key in the URL). FREE LIMIT: Up to 40 requests every 10 seconds, free TEST: once it's set up, ask it to look something up for you. If you can't make web requests yourself, give me the exact curl command with my key filled in so I can run it. Docs if you get stuck: https://developer.themoviedb.org/docs/getting-started

Keep API keys private. Only share yours with tools and people you trust.
