PubChem PUG REST

Everything about any chemical: structure, safety, and properties, free.

What it does

PubChem is the U.S. National Institutes of Health's huge chemical database, and its PUG REST API lets you query it with simple URLs. Look up any compound by name and get its structure, molecular formula, safety data, drug information, and test results. It is free, needs no key, and covers over 100 million chemical records.

What you can do with it

  • Look up the structure, formula, and safety info for any chemical by name
  • Build a chemistry study tool with real molecular data and images
  • Convert between chemical identifiers like names, InChI keys, and formulas

  2. Swap in any chemical name or identifier in the URL.
  3. Add /PNG at the end of some endpoints to get structure images instead of JSON.
  4. Keep requests under 5 per second to stay within the published limits.
