Netlify Functions

Serverless functions deployed alongside your site, free every month.

What it does

Netlify Functions lets you deploy serverless JavaScript or TypeScript functions right next to your website, reachable at your site's domain. New accounts are on a credit-based free plan with 300 credits per month, shared across bandwidth, builds, and compute, with no credit card required and a hard cap instead of surprise charges. Functions deploy automatically with your site from Git and support background and scheduled variants. Official setup docs walk through creating a function in minutes.

What you can do with it

  • Add a contact-form or newsletter backend to a static site.
  • Build small authenticated API endpoints without a server.
  • Run scheduled jobs like daily data syncs on the free plan.

Follow the quick-start steps

Use the provider's instructions below. There's no secret key to manage.

  1. Sign up for a free Netlify account, no card required.
  2. Connect a Git repo or deploy a site manually.
  3. Add a netlify/functions folder with a hello.js handler file.
  4. Deploy; the function goes live automatically.
  5. Call it at https://your-site.netlify.app/.netlify/functions/hello.
