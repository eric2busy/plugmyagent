PocketBase

One-file backend with database, auth, and file storage built in.

What it does

PocketBase is a free, open-source backend that ships as a single executable file, so you can run a full backend on any small server or laptop. It includes a SQLite database, email and OAuth login, file storage, an admin dashboard, and realtime data subscriptions with no monthly fees. You manage everything through its REST API or the built-in admin UI. There is no hosted cloud version, so you bring your own server.

What you can do with it

  • Launch a complete backend for a side project on a five-dollar server.
  • Store user accounts and files for a mobile or web app without a cloud bill.
  • Prototype an app locally with a real database and login system in minutes.

Follow the quick-start steps

Use the provider's instructions below. There's no secret key to manage.

  1. Download the PocketBase binary for your operating system.
  2. Run it with ./pocketbase serve to start the server.
  3. Open the admin dashboard at http://127.0.0.1:8090/_/ to create an admin account.
  4. Create collections for your data in the dashboard.
  5. Call the REST API from your app; no API key is needed for public rules you define.
