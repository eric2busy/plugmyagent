Shelly Device APIs

Local control of Shelly smart relays and sensors.

Open in PlugMyAgentOfficial docs

What it does

Shelly smart relays, plugs, and sensors expose a local HTTP and RPC API right on your network, so you can read status and control them without any cloud subscription. Everything works on your own LAN, which keeps latency low and privacy high. The official docs cover both the classic HTTP endpoints and the newer JSON-RPC interface.

What you can do with it

  • Toggle lights and outlets from your own scripts
  • Monitor power usage from Shelly EM devices
  • Build automations that run fully offline

Set it up

  1. Connect your Shelly device to your home Wi-Fi network.
  2. Find the device's IP address in your router or the Shelly app.
  3. Call the RPC endpoints directly from your LAN with no credentials.
  4. Use the documented methods to read status and toggle outputs.
  5. Subscribe to device webhooks if you want push updates.

Example request

http://192.168.33.1/rpc/Switch.GetStatus?id=2
