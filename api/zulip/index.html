Zulip

Threaded team chat that's actually free. 10,000 searchable messages on the hosted plan.

What it does

Zulip is team chat (like Slack or Discord for work) built around topics, so conversations stay organized instead of scrolling away. Their hosted Cloud plan is free with 10,000 searchable messages and 5 GB of storage. Genuinely usable for small teams. And the whole thing is open source, so you can self-host it for free with no limits.

What you can do with it

  • Run a small team's daily chat without paying per seat
  • Post automated alerts from your servers into a team channel
  • Host your own private chat server with the open-source version

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Zulip ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Create a free Zulip Cloud organization
  2. Invite your team and set up streams (channels) and topics
  3. Create a bot user to get an API key
  4. Send messages with the API or one of 30+ integrations
  5. Self-host on your own server if you outgrow the cloud limits
