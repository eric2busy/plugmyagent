IPinfo

Turn any IP address into a location, ISP, and company name.

What it does

IPinfo's geolocation API takes an IP address and returns its city, region, country, coordinates, ISP, and. On some fields. The company behind it. The free tier allows 50,000 requests a month with just an email signup, which is plenty for a personal site, analytics enrichment, or a fun 'where is this visitor from' widget. Paid fields like VPN/proxy detection exist, but the core geo data is free.

What you can do with it

  • Show approximate visitor locations on a website analytics dashboard
  • Flag logins from unexpected countries for a personal security check
  • Localize content by detecting a visitor's city or timezone

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for IPinfo ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Sign up free at ipinfo.io and copy your access token from the dashboard.
  2. Call https://ipinfo.io/{ip}/json?token=YOUR_TOKEN for any IP.
  3. Read city, region, country, loc (coordinates), and org fields from the JSON.
  4. Leave the IP out of the URL to look up your own connection's IP.
