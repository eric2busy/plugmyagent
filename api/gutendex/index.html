About

Gutendex is a simple, free API over Project Gutenberg's library of public-domain ebooks. You can search more than 70,000 books by title or author, filter by language or topic, and get download links in formats like EPUB and Kindle. No key or signup is needed at all.

Setup

  1. Paste the example URL into your browser to search ebooks instantly, no signup needed.
  2. Change the search text to any title, author, or keyword.
  3. Use filters like languages=en or topic=fiction to narrow results.
  4. Follow the formats links in each result to download the ebook file.
Sign up
Example
https://gutendex.com/books?search=dickens%20great

Use cases

  • Build a free ebook reader that searches classics by author or title
  • Download public-domain books in EPUB or Kindle format for a class
  • Create a 'book of the day' bot that picks from the full Gutenberg catalog
