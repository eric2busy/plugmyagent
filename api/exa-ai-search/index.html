Exa AI Search

Search that understands meaning, built for AI

What it does

Exa is a search engine designed for AI apps instead of humans. You query by meaning, not just keywords. It can return clean page text, summaries, and highlights, and it has special indexes for code, companies, people, and research papers. New accounts get $10 of free credits every month with no card required.

What you can do with it

  • Power an AI chatbot with high-quality, cited web answers
  • Find semantically similar pages instead of keyword matches
  • Extract clean article text for research pipelines

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Exa AI Search ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Sign up at dashboard.exa.ai. No card needed.
  2. Create an API key on the Keys page.
  3. POST to https://api.exa.ai/search with your key in the x-api-key header.
  4. Add "text": true to also get cleaned page content back.
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.
