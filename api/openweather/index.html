OpenWeather

Current weather and 5-day forecasts for anywhere on Earth.

What it does

OpenWeather has powered weather widgets and apps for over a decade. A free account gives you current conditions, a 5-day/3-hour forecast, air pollution data, and place lookup. It works worldwide and is very beginner friendly.

What you can do with it

  • Show right-now temperature and conditions on a website homepage
  • Get the 5-day forecast for a weekend trip
  • Check air pollution levels before a run

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for OpenWeather ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. 1. Create a free account and open the API keys page in your dashboard.
  2. 2. Copy your API key. It can take up to a couple of hours to activate.
  3. 3. Add &appid=YOUR_KEY plus &units=imperial (Fahrenheit) or metric (Celsius) to any request.
  4. 4. Use the free geocoding endpoints to turn city names into coordinates first.
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.

Set up OpenWeather for me so you can use it. HOW TO CALL IT https://api.openweathermap.org/data/2.5/weather?q=London&appid=PASTE_KEY_HERE AUTH: free API key. Mine: PASTE_KEY_HERE. Your key goes in the URL as ?appid=PASTE_KEY_HERE. FREE LIMIT: About 1,000 free calls per day on the free plan; no credit card required. TEST: once it's set up, ask it: “what's the weather in Los Angeles right now?”. If you can't make web requests yourself, give me the exact curl command with my key filled in so I can run it. Docs if you get stuck: https://openweathermap.org/current

Keep API keys private. Only share yours with tools and people you trust.
