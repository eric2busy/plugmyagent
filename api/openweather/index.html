What it does

OpenWeather has powered weather widgets and apps for over a decade. A free account gives you current conditions, a 5-day/3-hour forecast, air pollution data, and place lookup. It works worldwide and is very beginner friendly.

What you can do with it

  • Show right-now temperature and conditions on a website homepage
  • Get the 5-day forecast for a weekend trip
  • Check air pollution levels before a run

Set it up

  1. 1. Create a free account and open the API keys page in your dashboard.
  2. 2. Copy your API key. It can take up to a couple of hours to activate.
  3. 3. Add &appid=YOUR_KEY plus &units=imperial (Fahrenheit) or metric (Celsius) to any request.
  4. 4. Use the free geocoding endpoints to turn city names into coordinates first.

Example request

https://api.openweathermap.org/data/2.5/weather?q=London&appid=YOUR_KEY
