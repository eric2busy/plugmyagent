Harvest

Business Operations Free key (no card)

About

Harvest is time tracking and invoicing software with a $0-forever plan for one person and two projects, plus a 30-day no-card trial. Its API v2 covers time entries, projects, clients, and invoices with OAuth authentication. It is a strong fit for solo freelancers who bill by the hour.

Details

Free to start. You may need a free key, but no credit card.

Auth: Free key (no card)

Rate limit: 100 requests per 15 seconds per access token

Verified: 2026-09-13

Best for: time-tracking invoicing freelancers

Read the docs Back to catalog

Setup

  1. Sign up for the free Harvest plan or start the 30-day trial
  2. Create a personal access token or OAuth application in account settings
  3. Include your Harvest account ID in the Harvest-Account-Id header
  4. Send the token as a Bearer authorization header
  5. Call endpoints like /v2/time_entries and /v2/projects
  6. Stay within the 100-requests-per-15-seconds throttle
Sign up
Example
GET https://api.harvestapp.com/v2/time_entries with headers Authorization: Bearer TOKEN and Harvest-Account-Id: ACCOUNT_ID

Use cases

  • Track billable hours from project management tools
  • Auto-generate invoices from tracked time
  • Report project profitability from live time data
