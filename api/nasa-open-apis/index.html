NASA Open APIs

Science Data No key

AuthenticationNo key
Rate limitDemo key: about 30 requests/hour and 50/day (confirm on the portal); free personal key raises limits

Documentation: api.nasa.gov · Checked Sep 13, 2026

About

NASA's official collection of public APIs: the famous astronomy photo of the day (APOD), Mars rover photos, asteroid close-approach alerts, EPIC Earth images, the exoplanet archive, and more. You can start instantly with the shared demo key, and a free personal key raises your limits.

Details

No key needed. You can call it right away.

Auth: No key

Rate limit: Demo key: about 30 requests/hour and 50/day (confirm on the portal); free personal key raises limits

Verified: 2026-09-13

Best for: space apps educators science projects

Read the docs Back to catalog

Setup

  1. Open https://api.nasa.gov/ and use the DEMO_KEY example, or request your own free key
  2. Call any endpoint with ?api_key=YOUR_KEY
Sign up
Example
https://api.nasa.gov/planetary/apod?api_key=DEMO_KEY&count=1

Use cases

  • Show NASA's astronomy photo of the day in an app
  • Browse Mars rover photos by camera and date
  • Alert users to near-Earth asteroids
