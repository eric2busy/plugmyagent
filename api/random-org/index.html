Random.org

Truly random numbers, coin flips, and dice rolls from atmospheric noise.

What it does

Random.org generates randomness from real atmospheric noise instead of computer formulas, making it genuinely unpredictable. Through the API you can roll dice, flip coins, shuffle lists, pick lottery numbers, and generate random strings. A free beta key gets you started; no credit card.

What you can do with it

  • Fair dice rolls and coin flips in online games
  • Picking truly random giveaway winners
  • Shuffling playlists or randomizing quiz questions

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Random.org ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Get a free beta key at https://api.random.org/api-keys/beta (no card).
  2. Read the method list at https://api.random.org/json-rpc/4.
  3. Send POST requests to https://api.random.org/json-rpc/2/invoke with your key.
  4. Try generateIntegers for dice rolls or generateStrings for tokens.
  5. Track your remaining bits with the getUsage method.
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.
