eBird

Live bird sightings, hotspots, and rare-bird alerts from Cornell Lab.

What it does

eBird, run by the Cornell Lab of Ornithology, is the world's largest bird-sighting database. Its free API returns recent observations by region or coordinates, notable rare-bird sightings, birding hotspots, and the full bird taxonomy. A free API key is issued when you register, and requests carry it in a simple header.

What you can do with it

  • Show the latest bird sightings in your county on a map
  • Send alerts when a rare bird is reported near you
  • Find the best birding hotspots within driving distance

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for eBird ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Create a free eBird account, then visit the key request page to get your API key.
  2. Send the key as the X-eBirdApiToken header with every request.
  3. Look up your region code (e.g. US-CA for California) and request recent sightings.
  4. Explore hotspot, taxonomy, and notable-bird endpoints in the docs.
