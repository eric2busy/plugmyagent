Vercel REST API

Deploy and manage websites programmatically

What it does

Vercel's REST API lets you create deployments, manage domains, and handle environment variables without touching the dashboard. The free Hobby plan needs no credit card and is meant for personal, non-commercial projects. You authenticate with a personal access token and get everything back as JSON.

What you can do with it

  • Automated deployments from scripts or bots
  • Managing domains and projects across teams
  • Building custom deployment workflows

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Vercel REST API ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. 1. Sign up free at vercel.com.
  2. 2. Go to Account Settings > Tokens and create an access token.
  3. 3. Call the API with: Authorization: Bearer YOUR_TOKEN.
  4. 4. Try listing deployments: curl https://api.vercel.com/v6/deployments -H "Authorization: Bearer YOUR_TOKEN".
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.

Put it where the example above shows (usually an Authorization header or a key in the URL). FREE LIMIT: Rate limits are returned in response headers (X-RateLimit-Limit / Remaining / Reset).
