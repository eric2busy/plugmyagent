DocuSign

E-signature API with a free developer sandbox

Open in PlugMyAgentOfficial docsGet free access

What it does

DocuSign is the leading electronic signature platform with a full eSignature REST API. Developers get a free sandbox account with no credit card required, including demo envelopes for testing. Production sending requires a paid plan after the trial.

What you can do with it

  • Embed contract signing into an onboarding flow
  • Send offer letters and collect signatures automatically
  • Track envelope status from your own dashboard

Set it up

  1. Create a free DocuSign developer sandbox account
  2. Go to the Apps and Keys page to create an integration key
  3. Add a redirect URI and generate an RSA key pair for JWT auth
  4. Complete the OAuth consent flow once for your user
  5. Request a JWT access token with your RSA private key
  6. Call the eSignature REST API to send envelopes and manage documents

Example request

GET https://demo.docusign.net/restapi/v2.1/accounts/ACCOUNT_ID/envelopes with header Authorization: Bearer ACCESS_TOKEN
