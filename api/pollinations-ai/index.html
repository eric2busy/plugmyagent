Pollinations.AI

Free AI text and image generation, no key needed to start

What it does

Pollinations.AI is an open-source platform that generates text, images, audio, and video through simple web URLs. You can generate an image just by visiting a link, no signup required. It's fully open source on GitHub with interactive API docs. Optional free API keys unlock higher limits and dashboard features.

What you can do with it

  • Generating images from text prompts
  • Free AI chat in apps and bots
  • Prototyping AI features with zero setup

Follow the quick-start steps

Use the provider's instructions below. There's no secret key to manage.

  1. 1. No signup needed. Try: https://gen.pollinations.ai/image/a%20sunset%20over%20the%20ocean in your browser.
  2. 2. For text: POST to https://gen.pollinations.ai/v1/chat/completions with OpenAI-style JSON.
  3. 3. Read the interactive docs at gen.pollinations.ai/docs for all models and options.
  4. 4. Optionally grab a free key at enter.pollinations.ai for higher limits.
