Launch Library 2

Every rocket launch, past and future, in one feed.

What it does

The community-run database of orbital rocket launches worldwide. Upcoming schedules with countdowns, plus every launch since Sputnik in 1957, rockets, astronauts, space stations, and events. Free without a key for light use; a free API key raises the limits.

What you can do with it

  • Build a rocket launch countdown calendar
  • Track a specific provider's launch history
  • Show astronaut and mission details
