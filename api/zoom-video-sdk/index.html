Zoom Video SDK

Put Zoom's famous call quality inside your own app. Free monthly credits included.

What it does

The Zoom Video SDK lets you embed Zoom's video, audio, chat, and screen-sharing engine directly into your own app. With your branding, not Zoom's. Zoom gives every account a free monthly allowance (their docs describe it as 20 free credits a month, roughly 10,000 minutes), which is plenty to build and test with, and to run small apps for free.

What you can do with it

  • Add reliable video calls to a coaching or fitness app under your own brand
  • Build virtual classrooms with breakout-style sessions
  • Embed screen-sharing support calls in a help-desk tool

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Zoom Video SDK ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Create a Zoom developer account
  2. Create a Video SDK app and copy your SDK key and secret
  3. Build a session with the web, iOS, Android, or desktop SDK
  4. Generate a join signature (JWT) on your server for each user
  5. Join sessions from your app with your own branded interface
3
