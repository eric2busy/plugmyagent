Lorem Picsum

Free placeholder photos at any size, straight from a URL.

Open in PlugMyAgentOfficial docs

What it does

Lorem Picsum is "Lorem Ipsum for photos": ask for any width and height and it returns a real photo at exactly that size. The images come from Unsplash's curated collection, and you can request specific photos, grayscale versions, blurred versions, or a full browsable list. No signup, no key. Just URLs.

What you can do with it

  • Fill website layouts with realistic photos while designing a site
  • Mock up presentations, brochures, or ad campaigns before buying stock photos
  • Test image-loading features of an app with endless real photos

Set it up

  1. Paste https://picsum.photos/200/300 in a browser to get a random 200x300 photo
  2. Use ?grayscale or ?blur=2 for styled versions, or /id/237/200/300 for a specific photo
  3. Add ?random=1 to avoid browser caching when showing multiple images
  4. Use the URLs directly in <img> tags or design tools

Example request

https://picsum.photos/200/300
