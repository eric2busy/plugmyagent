Jikan API

A free unofficial doorway into MyAnimeList, the biggest anime and manga database on the internet.

What it does

Jikan gives you access to MyAnimeList's enormous catalog of anime and manga: titles, synopses, scores, rankings, characters, episodes, seasonal schedules, and reviews. MyAnimeList itself doesn't offer a rich public API, so Jikan fills that gap with a clean, key-free one that's perfect for anime projects.

What you can do with it

  • An anime blog auto-fills review posts with the show's score, synopsis, and character art
  • A fan builds a 'what to watch this season' tracker that updates every airing season
  • A Discord community bot answers questions like 'what's the rating of Frieren?'

Follow the quick-start steps

  2. Try an endpoint in your browser, e.g. api.jikan.moe/v4/anime/1
  3. Check the JSON response to see the anime details returned
  4. Drop the endpoint into your project and start building
