Wiktionary API

Dictionary definitions and language data, for free.

What it does

Wiktionary is the free multilingual dictionary from the Wikimedia Foundation, and the MediaWiki REST API exposes it programmatically. You can fetch definitions, parts of speech, pronunciations, and translations for words in hundreds of languages. No key is required. Just identify your app with a descriptive User-Agent header.

What you can do with it

  • Add word definitions to a language-learning app
  • Build a word-of-the-day bot or widget
  • Look up translations and pronunciations programmatically

Follow the quick-start steps

Use the provider's instructions below. There's no secret key to manage.

  1. No account or key is needed.
  2. Send requests to the Wiktionary REST endpoints for definitions.
  3. Include a descriptive User-Agent header identifying your app.
  4. Parse the returned JSON for definitions, pronunciations, and translations.
  5. Switch the language subdomain (like fr.wiktionary.org) for other languages.
