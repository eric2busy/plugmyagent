Stream Chat

Polished in-app messaging with free build access and a Maker program for small teams.

What it does

Stream's Chat API gives you fast, good-looking in-app messaging. Think Slack-style channels with threads, reactions, typing indicators, and file sharing. You can build and test for free, and their Maker program is aimed at small teams (fewer than five people, under $10k monthly revenue) getting started. Treat this as build/Maker access rather than an unlimited free production plan.

What you can do with it

  • Launch a startup's in-app chat free while building the product
  • Build a support inbox with threads and reactions for agents
  • Add event or livestream chat to a community app

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Stream Chat ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Sign up for a Stream account
  2. Create a Chat app and copy your API key and secret
  3. Create a user and channel with the server SDK
  4. Add the client SDK or UI components to your app
  5. Connect, send messages, and add reactions and threads
