U.S. Census Data API

US Government Data Free key (no card)

About

The official Census Bureau API gives you the same demographic and economic data behind American Community Survey reports and the decennial census: population counts, income, education, housing, race, and more, down to the neighborhood, county, or congressional district level. Everything is pulled straight from the source, updated as new survey waves are released. Responses come back as simple JSON tables you can read in a browser.

Details

Free to start. You may need a free key, but no credit card.

Auth: Free key (no card)

Rate limit: Keyed requests: generous free allowance; small unauthenticated requests also work. No fixed public quota published.

Verified: 2026-09-13

Best for: personal business developer fun

Setup

  1. Open the API page and sign up with your email to get a free key (takes about a minute).
  2. Pick the dataset you want from the documentation page, e.g. the American Community Survey (ACS).
  3. Build a URL like the example: choose variables with 'get=', then geography with 'for=' and 'in='.
  4. Paste the URL in a browser with '&key=YOUR_KEY' to see the JSON result instantly.
Sign up
Example
https://api.census.gov/data/2024/acs/acs5/subject?get=NAME,S0101_C01_032E&for=county:*&in=state:51

Use cases

  • Look up your neighborhood's median income, rent, and education levels for a move or a report
  • Power a local-news or real-estate dashboard with live demographic stats
  • Pull official numbers for grant applications, market research, or school projects
