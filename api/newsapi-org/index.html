What it does

NewsAPI.org collects current news stories from newspapers, magazines, and blogs around the world and hands them to you as clean, structured data. You can search every article for any keyword, or just grab the top headlines for a country or topic. The free plan is meant for personal projects, learning, and testing. Not for live apps or businesses.

What you can do with it

  • Build a morning news digest of the topics you care about
  • Power a personal dashboard or hobby website with live headlines
  • Prototype an app feature before paying for a commercial news feed

Set it up

  1. Go to newsapi.org and create a free account.
  2. Copy the API key shown on your dashboard.
  3. Add the key to the end of any request URL as ?apiKey=YOUR_KEY.
  4. Start with /v2/top-headlines?country=us to see live headlines.

Example request

https://newsapi.org/v2/everything?q=artificial+intelligence&language=en&apiKey=YOUR_API_KEY
