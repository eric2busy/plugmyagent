Slack Incoming Webhooks

Pipe notifications and alerts from any app straight into a Slack channel, free on every Slack plan.

What it does

Slack's incoming webhooks work exactly like Discord's: Slack gives you a private URL tied to a channel, and anything posted to it becomes a message. It's the standard way monitoring tools, CRMs, and automations send alerts to Slack teams. Messages can use Slack's formatting and rich layouts. Free workspaces get it too.

What you can do with it

  • Alert your team in Slack when a new support ticket or order arrives
  • Post daily sales summaries from a script into a #wins channel
  • Get pinged in Slack when a website form is submitted

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Slack Incoming Webhooks ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Go to api.slack.com/apps and click Create New App, then From scratch
  2. Name the app, pick your Slack workspace, and click Create App
  3. In the left sidebar, open Incoming Webhooks and toggle it On
  4. Click Add New Webhook to Workspace, pick a channel, and click Allow
  5. Copy the webhook URL and paste it into your tool or script as the destination
