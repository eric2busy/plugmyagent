Postiz

Open-source social scheduling with a public API; hosted trial or free self-host.

Open in PlugMyAgentOfficial docsGet free access

What it does

Postiz is an open-source social media scheduling tool with a public API for creating posts, managing channels, and reading analytics across networks. The hosted version offers a 7-day free trial; if you want free forever, you can self-host the AGPL-licensed version on your own server. A practical pick for developers who want a Buffer-style API without the enterprise price tag.

What you can do with it

  • Queue a month of social posts from a content calendar
  • Build a client-facing posting dashboard
  • Automate cross-posting to every network at once

Set it up

  1. Start the 7-day hosted trial, or self-host the open-source version
  2. Connect your social channels
  3. Generate a public API token
  4. Create and schedule posts through the API
  5. Confirm API access is included in your trial before building on it

Example request

POST https://api.postiz.com/public/v1/posts with header Authorization: Bearer <token> and your post content plus channels
