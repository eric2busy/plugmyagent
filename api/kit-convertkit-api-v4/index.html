Kit (ConvertKit) API v4

Creator-focused email API for subscribers, tags, forms, and sequences.

What it does

Kit (formerly ConvertKit) is the email platform built for creators, and its v4 API is clean and modern. You can manage subscribers, tags, forms, and sequences with an API key or OAuth. The free Newsletter plan supports a large subscriber list with API access, so it is a strong free option for creator newsletters and lead magnets.

What you can do with it

  • Add ebook downloaders to a nurture sequence automatically
  • Tag subscribers by which lead magnet they chose
  • Sync new customers from your store into Kit

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Kit (ConvertKit) API v4 ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Create a free Kit account
  2. Generate an API key (or set up OAuth for multi-user apps)
  3. Test by listing your subscribers
  4. Use tags and forms to organize new signups
  5. Check the docs for which actions your plan supports before automating sends
