BLS Public Data API

Unemployment rates, job growth, and inflation data from the Bureau of Labor Statistics.

Open in PlugMyAgentOfficial docsGet free access

What it does

The Bureau of Labor Statistics publishes the numbers behind the monthly jobs report, inflation (CPI) readings, and pay figures for hundreds of occupations, and this free API lets you pull that time-series data directly. You ask for a series ID (a code for one statistic) and get years of monthly or quarterly numbers back as JSON. With a free key you get 500 queries a day, plenty for dashboards, homework, or salary research.

What you can do with it

  • Chart unemployment trends in your state over the last 20 years
  • Compare wages for occupations across metro areas when planning a career move
  • Feed the latest inflation numbers into a personal finance tracker

Set it up

  1. Register for a free API key on the BLS registration page (email signup, key lasts a year).
  2. Find the series ID for the stat you want in the BLS docs or with the Series Report search tool.
  3. Send a POST request to https://api.bls.gov/publicAPI/v2/timeseries/data/ with the series ID and your key.
  4. Read the returned JSON array of yearly or monthly values in your app or a spreadsheet.

Example request

https://api.bls.gov/publicAPI/v2/timeseries/data/?seriesid=CUUR0000SA0&api_key=YOUR_KEY
