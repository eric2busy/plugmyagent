Firebase Cloud Messaging

Google's free push notification service. Unlimited notifications on every Firebase plan.

What it does

Firebase Cloud Messaging (FCM) is how apps send push notifications to Android and iOS phones. And it's free on every Firebase plan, even in production. You register devices, then send notifications from your server or the Firebase console. Since it's part of Google's Firebase, it plugs right into the rest of the Firebase toolkit.

What you can do with it

  • Notify users of new messages, orders, or mentions in your app
  • Send breaking-news alerts to a news app's subscribers
  • Remind users about expiring carts or upcoming appointments

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Firebase Cloud Messaging ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Create a free Firebase project
  2. Add the Firebase SDK to your Android/iOS app
  3. Collect each device's registration token
  4. Get a service-account credential for your server
  5. Send notifications with the FCM HTTP v1 API
