About

Postmark is the email service developers reach for when receipts, password resets, and order confirmations absolutely must arrive. Their free Developer plan gives you 100 emails a month with no expiration date. It never runs out. Known for excellent deliverability and simple, honest pricing.

Setup

  1. Sign up for a free Postmark account
  2. Create a server to get your server API token
  3. Verify the domain or address you'll send from
  4. Send a test email from the dashboard
  5. Add the API call to your app for receipts, invites, and alerts
Sign up
Example
Send an email: POST https://api.postmarkapp.com/email with a server token and From/To/Subject/HtmlBody

Use cases

  • Send password-reset and welcome emails that actually reach inboxes
  • Deliver order receipts and shipping confirmations
  • Send low-volume alerts from a side project for free, forever
