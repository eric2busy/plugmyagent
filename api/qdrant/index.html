What it does

Qdrant is an Apache-2.0 vector database written in Rust, built for agent memory and semantic search at speed. The free cloud tier gives you a 1 GB cluster free forever with no card required, and you can self-host the whole thing free.

What you can do with it

  • Agent memory
  • Semantic search
  • RAG pipelines

Set it up

  1. 1. Sign up at cloud.qdrant.io and create a free cluster.
  2. 2. Copy the cluster URL and API key from the dashboard.
  3. 3. Create a collection, upsert vectors, and search by similarity.

Example request

PUT https://YOUR-CLUSTER.cloud.qdrant.io:6333/collections/my_collection --header "api-key: YOUR_API_KEY"
