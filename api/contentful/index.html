Contentful

Databases Free tier (card may be required)

About

Contentful is a hosted headless content platform where editors manage content in a web app and developers pull it through fast CDN-backed APIs. The free plan includes up to 10 users, one Starter Space, 100,000 API calls per month, and 50 GB of CDN bandwidth, enforced as hard caps. Content is delivered through the Content Delivery API, with a separate Preview API for draft content. It is a solid pick for small marketing sites and blogs that want a polished editor without self-hosting.

Setup

  1. Sign up for a free Contentful account and create a space.
  2. Define content models for your content types.
  3. Add entries through the web app.
  4. Create a Content Delivery API access token in space settings.
  5. Fetch entries with the token as the access_token parameter.
Sign up
Example
curl "https://cdn.contentful.com/spaces/{space_id}/entries?access_token={token}"

Use cases

  • Manage blog and marketing content without deploying code changes.
  • Feed the same content to a website, app, and newsletter.
  • Let a small team edit content while developers consume it via API.
