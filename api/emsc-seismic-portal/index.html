EMSC Seismic Portal

Europe's real-time earthquake monitoring feed.

What it does

The European-Mediterranean Seismological Centre's earthquake API. The European counterpart to USGS, with strong coverage of Europe, the Mediterranean, and the world. Uses the same FDSN standard, so it pairs naturally with the USGS catalog. No key needed.

What you can do with it

  • Cross-check quake data with a second source
  • Build a Europe-focused seismic alert app
  • Compare magnitude reports from two agencies
