Open States API v3

Every state legislature: bills, votes, and lawmakers in all 50 states.

Open in PlugMyAgentOfficial docsGet free access

What it does

Open States (now run by Plural Policy) tracks bills, votes, legislators, committees, and events across all 50 state legislatures plus D.C. and Puerto Rico. The state-level equivalent of the Congress.gov API. The v3 API returns clean JSON you can search by bill number, sponsor, subject, or state. A free key gets you in, with a few hundred requests a day.

What you can do with it

  • Track a California bill from introduction through votes to the governor's desk
  • Find every bill your state legislator sponsored this session
  • Compare how different states are legislating on the same topic

Set it up

  1. Sign up for a free key on the Open States signup page.
  2. Read the v3 docs to learn the main endpoints: bills, people, votes, events.
  3. Call an endpoint with your key, e.g. bills filtered by state and session.
  4. Use the 'jurisdiction' parameter to switch between states.

Example request

https://v3.openstates.org/bills?jurisdiction=California&session=20232024&apikey=YOUR_KEY
