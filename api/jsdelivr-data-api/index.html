jsDelivr Data API

Free metadata API for npm and GitHub packages

What it does

jsDelivr is a free content delivery network that hosts JavaScript libraries and npm packages. Its public Data API tells you a package's versions, file lists, entry points, and download stats. No signup, no key, no rate limits. It's perfect for dashboards, dependency tools, and package search features.

What you can do with it

  • Listing versions and files of an npm package
  • Showing download statistics on dashboards
  • Resolving package files for web tools
