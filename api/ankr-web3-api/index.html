Ankr Web3 API

Blockchain Free key (no card)

About

Ankr's Web3 API gives developers RPC access plus indexed 'Advanced' APIs (token prices, balances, NFTs, transactions) across many chains. The Freemium plan (sign-in required) grants 200 million API credits/month, 30 Node API requests/second, and 30 Advanced API requests/minute per project.

Details

Free to start. You may need a free key, but no credit card.

Auth: Free key (no card)

Rate limit: Freemium (free): 200M credits/month, 30 Node API req/sec, 30 Advanced API req/min.

Verified: 2026-09-13

Best for: Multi-chain dashboards DeFi portfolios RPC fallbacks

Read the docs Back to catalog

Setup

  1. Sign in free at ankr.com/rpc and create a project.
  2. Copy your project API key.
  3. Use RPC URLs like https://rpc.ankr.com/eth/YOUR_KEY.

Example
POST https://rpc.ankr.com/eth/YOUR_KEY  {"jsonrpc":"2.0","method":"eth_getBalance","params":["0x...","latest"],"id":1}

Use cases

  • Multi-chain wallet and portfolio views
  • DeFi position tracking across chains
  • A free RPC fallback for Web3 apps
