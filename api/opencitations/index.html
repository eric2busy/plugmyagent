OpenCitations

Scholarly No key

About

OpenCitations publishes open citation data showing which scholarly works cite which other works. Its free API lets you get citation counts and citation lists for any paper with a DOI. No key is needed for basic use, and a free optional token raises your limits; it works with identifiers rather than keyword topic search.

Details

No key needed. You can call it right away.

Auth: No key

Rate limit: No published anonymous limit; an optional free token from opencitations.net/accesstoken raises quotas.

Verified: 2026-09-13

Best for: personal developer

Read the docs Back to catalog

Setup

  1. Paste the example URL into your browser with any paper's DOI to get its citation count, no signup needed.
  2. Swap in your own DOI after doi: in the URL.
  3. Explore the docs for citation lists, reference lists, and metadata endpoints.
  4. Optional: get a free access token to raise your limits.
Sign up
Example
https://api.opencitations.net/index/v2/citation-count/doi:10.1038/s41586-020-2649-2

Use cases

  • Get the citation count for any paper from its DOI
  • List all papers that cite a specific article for a literature review
  • Build a research-impact dashboard using open citation data
