What it does

USAJOBS is the official job board for the U.S. federal government, and its search API lets you query every open posting with filters for keyword, location, department, pay grade, remote status, and hiring path. Each result includes the job summary, salary range, closing date, and the direct application link. A free key is required and sent in a request header.

What you can do with it

  • Find remote federal jobs paying over $80k anywhere in the U.S.
  • Build a daily alert for new openings at a specific agency
  • Compare federal pay grades for the same role across cities

Set it up

  1. Request a free API key on the USAJOBS developer site.
  2. Add three headers to every request: Host, User-Agent (your email), and Authorization-Key (your key).
  3. Start with the tutorial's example search in the docs to see the JSON format.
  4. Add filters like LocationName, PayGradeLow, or RemoteIndicator to narrow results.

Example request

https://data.usajobs.gov/api/search?Keyword=analyst&LocationName=Los%20Angeles,%20California
