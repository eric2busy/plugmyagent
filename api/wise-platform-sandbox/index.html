Wise Platform Sandbox

Build and test cross-border payment flows for free

What it does

Wise's Platform API lets developers create quotes, recipients, and international transfers, and the sandbox environment lets you test everything with fake money. You can use it to prototype a payout feature that sends money abroad, to test multi-currency balance logic, or to learn how OAuth-based payment APIs handle authentication and webhooks. The sandbox is free and uses the same endpoints as production, so code you test there transfers over when you go live.

What you can do with it

  • Prototype a cross-border payout feature for an app
  • Test multi-currency balance and quote logic
  • Learn OAuth payment API auth and webhooks safely

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Wise Platform Sandbox ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Read the Wise Platform docs to understand profiles, quotes, and transfers.
  2. Register for a Wise Platform sandbox account and get your client ID and secret.
  3. Exchange your credentials for an OAuth access token via POST /oauth/token.
  4. Point your code at https://api.wise-sandbox.com and create a test quote.
  5. Subscribe to sandbox webhooks to watch transfer status changes in real time.
