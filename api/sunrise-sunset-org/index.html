Sunrise-Sunset.org

Exact sunrise, sunset, and golden-hour times for any place.

Open in PlugMyAgentOfficial docs

What it does

Give it coordinates and get sunrise, sunset, solar noon, day length, civil/nautical/astronomical twilight, and golden hour times. Timezone-aware. Completely free with no key; just credit sunrise-sunset.org.

What you can do with it

  • Plan golden-hour photo shoots
  • Trigger smart lights at sunset
  • Show day length for travel destinations

Set it up

  1. No setup. Call the endpoint with lat and lng parameters

Example request

https://api.sunrise-sunset.org/v2?lat=36.7201600&lng=-4.4203400
