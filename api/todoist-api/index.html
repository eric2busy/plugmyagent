Todoist API

Add, complete, and manage your to-do tasks from any app. Free with a Todoist account.

What it does

Todoist's API (v1) gives programmatic access to your tasks, projects, labels, reminders, and comments. It's free to use with any Todoist account. You just grab a personal API token from settings. Great for personal productivity hacks, like adding tasks from email, voice notes, or other apps without opening Todoist.

What you can do with it

  • Add tasks to Todoist straight from your email or a web form
  • Log completed tasks into a spreadsheet or journal automatically
  • Build a personal dashboard showing today's tasks anywhere

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Todoist API ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Sign up for free at todoist.com and open the app
  2. Go to Settings → Integrations → Developer and copy your personal API token
  3. Send requests with the header: Authorization: Bearer <redacted>
  4. Try creating a task with the example call in their docs
  5. Add it to your automations (e.g. Zapier, Make, or a simple script)
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.

Keep API keys private. Only share yours with tools and people you trust.
