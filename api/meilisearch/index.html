Meilisearch

Blazing-fast open-source search engine you host yourself for free.

What it does

Meilisearch is a free, open-source search engine that adds typo-tolerant, instant search to any app or website. The self-hosted version is free forever with no usage caps, and you run it with a single Docker command. Meilisearch Cloud offers a 14-day trial that needs no credit card if you want a managed option. It is a popular choice for site search, product catalogs, and documentation search.

What you can do with it

  • Add instant, typo-tolerant search to an online store or blog.
  • Power search across help docs or a knowledge base.
  • Build faceted product filtering without paying for a hosted search service.

Follow the quick-start steps

Use the provider's instructions below. There's no secret key to manage.

  1. Install Meilisearch with Docker or download the binary.
  2. Start it with a master key for admin access.
  3. Create an index and add your documents via the API.
  4. Configure searchable fields and ranking rules if needed.
  5. Query the search endpoint from your app with the master key or a search-only key.
