Vonage APIs

€2 of free trial credit for texts, calls, and verification. No credit card needed.

What it does

Vonage (formerly Nexmo) is a big communications platform for sending SMS, making calls, and verifying phone numbers. New accounts get €2 of free trial credit with no card required. Enough to test texting and calling for real. During the trial you can text your own number plus four extra verified test numbers, and make calls to your registered number.

What you can do with it

  • Test an SMS notification feature before committing to a provider
  • Verify customer phone numbers during onboarding
  • Build a click-to-call feature for a sales team

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Vonage APIs ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Sign up for a free Vonage account
  2. Copy your API key and secret from the dashboard
  3. Send a test SMS to your own phone from the dashboard or API
  4. Add up to four more test phone numbers and verify them
  5. Add top-up credit when you're ready for production
3
