Retell AI

Launch AI voice agents that call and answer, with free trial credits.

What it does

Retell AI lets you build human-sounding AI voice agents that make and receive phone calls: appointment reminders, lead follow-ups, receptionist duties. Its API creates calls, configures agents with prompts and voices, and streams transcripts and outcomes back to your app. You can start a free trial without talking to sales, and trial credits cover real test calls.

What you can do with it

  • Have an AI agent call new leads within minutes of signup
  • Automate appointment reminders and rescheduling by phone
  • Build an after-hours receptionist that takes messages

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Retell AI ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Sign up at retellai.com and open the dashboard
  2. Create an API key and a voice agent with your prompt
  3. Buy or connect a phone number in the dashboard
  4. Create a test phone call through the API
  5. Read the call transcript and tune the agent's prompt
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.

Set up Retell AI for me so you can use it. HOW TO CALL IT POST https://api.retellai.com/v2/create-phone-call with header Authorization: Bearer <key>, plus from_number, to_number, and agent_id AUTH: free API key. Mine: PASTE_KEY_HERE. Put it where the example above shows (usually an Authorization header or a key in the URL). Heads up: this is a free trial. Check how long it lasts. FREE LIMIT: Free trial with starter credits and concurrent-call limits; add payment details when you are ready to continue. TEST: once it's set up, ask it for today's top headlines. If you can't make web requests yourself, give me the exact curl command with my key filled in so I can run it. Docs if you get stuck: https://docs.retellai.com/

Keep API keys private. Only share yours with tools and people you trust.
