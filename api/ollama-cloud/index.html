About

Ollama Cloud takes the open models builders already love (Qwen, GPT-OSS, DeepSeek, Mistral Small) and hosts them in the cloud with tool calling built in. The $0 Free plan gives you monthly-refreshing starter credits with no card or phone number, and the API is OpenAI-compatible. It is the easiest way to run open models from a name agent builders already trust.

Setup

  1. Go to ollama.com/cloud and create an account (no card or phone needed).
  2. Create an API key in your dashboard.
  3. Point your OpenAI-compatible client at https://ollama.com/v1.
  4. Pick a starter model and start making requests; your credits refresh monthly.
