What it does

Bybit's v5 API offers keyless public market data. Tickers, order books, trades, candles, funding rates, open interest, and options/volatility surfaces. With per-endpoint rate limits around 10 requests/second and a 600-requests-per-5-seconds IP ceiling. A free testnet supports simulated trading for bot development.

What you can do with it

  • Funding-rate and derivatives dashboards
  • Liquidation and open-interest alerts
  • Paper-trading crypto bots on testnet

Set it up

  1. No signup needed. GET public endpoints like /v5/market/tickers.
  2. For trading practice, create a free account and use the Bybit testnet.
  3. Create API keys with read/trade permissions scoped to testnet.

Example request

GET https://api.bybit.com/v5/market/tickers?category=spot
