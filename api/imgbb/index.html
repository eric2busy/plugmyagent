ImgBB

Dead-simple free image uploads via API

Open in PlugMyAgentOfficial docs

What it does

ImgBB's API does one thing well: you send it an image and get back a shareable link. Signup is free with no credit card, and you can upload from a file, base64 data, or even just an image URL. It's the fastest way to get image hosting into a small app or script.

What you can do with it

  • Quick image hosting for apps
  • Upload buttons in prototypes
  • Storing screenshots from scripts

Set it up

  1. 1. Sign up at imgbb.com and get your API key.
  2. 2. POST to https://api.imgbb.com/1/upload with your key and the image.
  3. 3. Read the JSON response. It includes direct links and thumbnails.
  4. 4. Use the display_url in your app or page.

Example request

POST https://api.imgbb.com/1/upload
