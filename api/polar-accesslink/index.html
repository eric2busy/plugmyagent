Polar AccessLink

Heart rate, training, activity, and sleep data from Polar devices.

What it does

Polar's AccessLink API gives you access to the data collected by Polar watches and heart-rate monitors. Any Polar Flow user can create a client for free. No business application needed. It covers training sessions, daily activity, sleep, continuous samples, and device info.

What you can do with it

  • Analyze heart-rate zones and training load from your workouts
  • Track sleep and recovery trends across weeks
  • Feed Polar data into a personal health dashboard

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Polar AccessLink ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Create a free Polar Flow account and pair your Polar device.
  2. Open the Polar API v4 documentation page and register a new client.
  3. Note your client ID and client secret from the client dashboard.
  4. Register the users who will connect their Polar data to your app.
  5. Use OAuth2 to get an access token, then pull data from the v4 endpoints.
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.

Set up Polar AccessLink for me so you can use it. HOW TO CALL IT GET https://www.polaraccesslink.com/v4/data with your OAuth access token as a Bearer header AUTH: free API key. Mine: PASTE_KEY_HERE. Put it where the example above shows (usually an Authorization header or a key in the URL). FREE LIMIT: 3,000 requests/15 minutes and 100,000 requests/day TEST: once it's set up, ask it to look up one item you know. If you can't make web requests yourself, give me the exact curl command with my key filled in so I can run it. Docs if you get stuck: https://www.polar.com/polar-api-v4/

Keep API keys private. Only share yours with tools and people you trust.
