Supabase

Free Postgres database plus auth, storage, and APIs

What it does

Supabase gives you a full Postgres database in the cloud with an instant REST API generated for every table. The free tier includes 500 MB of database storage, 1 GB of file storage, and login for up to 50,000 monthly users. You manage everything from a simple dashboard. No server setup.

What you can do with it

  • App and website backends
  • User login and auth
  • Storing files and user data

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Supabase ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. 1. Sign up at supabase.com and click New Project.
  2. 2. Pick a name, password, and region. Your database spins up in ~2 minutes.
  3. 3. In the dashboard, open the Table Editor and create your first table.
  4. 4. Copy the anon API key from Project Settings > API and use it in the REST examples from the docs.
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.

Set up Supabase for me so you can use it. HOW TO CALL IT GET https://YOUR-PROJECT.supabase.co/rest/v1/todos --header "apikey: YOUR_ANON_KEY" AUTH: free API key. Mine: PASTE_KEY_HERE. Put it where the example above shows (usually an Authorization header or a key in the URL). FREE LIMIT: Unlimited API requests on free tier; projects pause after inactivity and wake on next use. TEST: once it's set up, ask it to fetch one small thing, like a repo or a fresh UUID. If you can't make web requests yourself, give me the exact curl command with my key filled in so I can run it. Docs if you get stuck: https://supabase.com/docs

Keep API keys private. Only share yours with tools and people you trust.
