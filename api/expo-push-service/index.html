Expo Push Service

Push Notifications No key

AuthenticationNo key
Rate limitFree; 600 notifications/sec per project, 100 per request, 1,000 receipt IDs per request

Documentation: docs.expo.dev · Checked Sep 13, 2026

About

Expo's Push Service lets React Native apps send push notifications without wrestling with Apple's and Google's push servers directly. It's free to use, handles up to 600 notifications per second per project (100 per request), and you get delivery receipts to confirm messages arrived. Ideal if your app is built with Expo.

No key needed. You can call it right away.

Setup

  1. Build your app with Expo and add the Notifications library
  2. Ask the user for notification permission and get their Expo push token
  3. Send pushes to that token with the Expo Push API
  4. Check receipts to confirm delivery
  5. No server keys from Apple or Google required to start
Sign up
Example
Send a push: POST https://exp.host/--/api/v2/push/send with to (Expo push token), title, and body

Use cases

  • Add notifications to an Expo-built app in an afternoon
  • Prototype push features without Apple/Google developer setup
  • Send transactional alerts from a React Native MVP
