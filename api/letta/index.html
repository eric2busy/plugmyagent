What it does

Letta is the open-source successor to MemGPT, and it solves the problem every agent builder hits: the agent wakes up blank every session. Letta gives agents stateful memory with memory blocks, archival recall, and sleep-time consolidation, so they accumulate knowledge and learn across conversations instead of starting over. It is self-hosted under Apache 2.0, free to run locally, with an optional managed cloud when you outgrow your laptop. If you want an agent that remembers you, start here.

What you can do with it

  • Build a personal assistant that remembers your preferences
  • Give a support agent long-term context on each customer
  • Prototype sleep-time learning where agents consolidate memories

Set it up

  1. Install with the command above
  2. Configure your model API key, any OpenAI-compatible endpoint works
  3. Create an agent and give it memory blocks describing what to remember
  4. Chat across sessions and watch it recall earlier conversations

Example request

npm install -g @letta-ai/letta-code
