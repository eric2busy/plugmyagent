Pokemon TCG

Games Free key (no card)

About

The Pokemon TCG API covers 18,000+ real trading cards with high-res images, market prices, rarities, and set details. Search by name, type, or set, and page through results. Works without a key at low volume; a free key (no card) raises you to 20,000 requests a day.

Details

Free to start. You may need a free key, but no credit card.

Auth: Free key (no card)

Rate limit: 1,000 requests/day without a key; 20,000/day with the free key.

Verified: 2026-09-13

Best for: pokemon card-games collecting

Read the docs Back to catalog

Setup

  1. Sign up free at https://dev.pokemontcg.io (no card) and copy your key.
  2. Send it as an 'X-Api-Key' header with each request.
  3. Search cards: https://api.pokemontcg.io/v2/cards?q=name:charizard.
  4. Get one card: https://api.pokemontcg.io/v2/cards/xy7-54.
  5. List sets: https://api.pokemontcg.io/v2/sets.

Use cases

  • A card collection tracker with live prices
  • Deck-building helpers for players
  • Browsing sets and rarities before buying packs
