QuickChart

Charts, QR codes, and graphs generated from a simple URL.

Open in PlugMyAgentOfficial docs

What it does

QuickChart turns a short description into chart images: bar, line, pie, radar, and more - plus QR codes and even Graphviz diagrams. Everything works through plain URLs with no key, so you can embed live charts anywhere.

What you can do with it

  • QR codes for menus, tickets, and Wi-Fi sharing
  • Charts in reports, emails, and dashboards
  • Graphs in chat bots and notifications

Set it up

  1. Read the docs at https://quickchart.io/documentation/.
  2. QR code: https://quickchart.io/qr?text=Hello+World&size=200.
  3. Chart: https://quickchart.io/chart?c={type:'bar',data:{labels:['A','B'],datasets:[{data:[1,2]}]}}.
  4. Use the 'chart' builder on their site to design without coding.
  5. Embed the URL in an <img> tag - no key needed.

Example request

https://quickchart.io/qr?text=https://example.com&size=200
