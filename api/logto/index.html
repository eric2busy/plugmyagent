Logto

Open-source identity platform free for 50,000 monthly users.

What it does

Logto is an open-source identity and access management platform you can self-host for free, with a managed cloud that is free for up to 50,000 monthly active users. The free cloud plan also includes 50,000 access tokens per month, three applications, one machine-to-machine app, and one custom domain. Free development tenants unlock all features for testing. Note that role-based access control moved off the free plan after October 2025, so check current plan details if you need RBAC.

What you can do with it

  • Add standards-based OIDC login to web and mobile apps.
  • Run your own identity server with no per-user cost.
  • Manage multiple applications under one identity tenant.

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Logto ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Sign up for Logto Cloud free or self-host with Docker.
  2. Create an application and note the app ID and endpoint.
  3. Configure redirect URIs for your login flow.
  4. Integrate with the Logto SDK or any OIDC client.
  5. Use the Management API with a machine-to-machine token for admin tasks.
3
