Axiom

Log analytics and monitoring with a generous always-free tier.

What it does

Axiom is a log management and observability platform where you ship logs and events through a simple ingest API and query them with a fast analytics language. The always-free tier includes 25 GB of storage, 500 GB of monthly data loading, 10 GB-hours of query compute per month, 30-day retention, three datasets, and three monitors for one user. It is a practical free alternative to expensive log platforms for side projects and small teams.

What you can do with it

  • Centralize logs from an app or server for searching and alerting.
  • Set up monitors that alert when errors spike.
  • Analyze API usage and performance from event data.

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Axiom ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Create a free Axiom account and organization.
  2. Create a dataset to hold your logs.
  3. Generate an API token with ingest permission.
  4. Send events to the ingest endpoint with the token.
  5. Query and chart your data in the Axiom dashboard.
