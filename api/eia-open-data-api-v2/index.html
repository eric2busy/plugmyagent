EIA Open Data API v2

U.S. energy stats: gas prices, electricity, oil, renewables, and emissions.

What it does

The U.S. Energy Information Administration collects the country's energy data, and this API v2 opens it all up: retail gasoline prices, electricity generation by source, oil production, natural gas storage, renewable capacity, emissions, and international energy stats. You pick a dataset from the browser, filter by date or region, and get up to 5,000 rows of JSON per request with a free key.

What you can do with it

  • Chart gas prices in your state over the last decade
  • Compare how much electricity each state gets from solar and wind
  • Fuel a newsletter with weekly oil-inventory and natural-gas numbers

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for EIA Open Data API v2 ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Register for a free key on the EIA Open Data portal.
  2. Use the API browser on the docs page to pick a dataset and facets (fuel, region, date).
  3. Copy the generated URL and add your api_key parameter.
  4. Fetch it from your script or browser and read the 'data' array in the JSON.
3
