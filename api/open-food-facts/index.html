Open Food Facts

Free, crowdsourced food product database with barcode lookup.

What it does

Open Food Facts is a free, crowdsourced database of food products from around the world, backed by a nonprofit. You can look up products by barcode and get nutrition facts, ingredients, allergens, and Nutri-Score ratings with no API key for read access. Write access is available too, but requires authentication and a descriptive User-Agent.

What you can do with it

  • Build a barcode scanner that shows nutrition facts
  • Look up ingredients and allergens for recipes
  • Research product nutrition data for a diet app

Follow the quick-start steps

Use the provider's instructions below. There's no secret key to manage.

  1. No account or key is needed for read access.
  2. Start calling the public product endpoints directly from your app.
  3. Add a descriptive User-Agent header identifying your app to every request.
  4. Use the v3 API for new projects.
  5. Create an account only if you want to contribute product data back.
