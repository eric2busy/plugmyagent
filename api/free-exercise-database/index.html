Free Exercise Database

Fitness No key

About

This is a community exercise database released free and open source on GitHub, with 317 exercises and 593 video demos, GIF previews, images, and step-by-step instructions. The data is plain JSON files you can download and use without any key or account. You can also run its included demo server to test a ready-made exercise API.

Details

No key needed. You can call it right away.

Auth: No key

Rate limit: No limit; the data is static files you download and host yourself.

Verified: 2026-09-13

Best for: personal developer

Setup

  1. Open the GitHub page and click the green Code button to download or clone the repository.
  2. Find the JSON files containing exercises, videos, and instructions in the folder.
  3. Load those files directly in your app or on your own server, no key needed.
  4. Optional: run the included demo server to test API-style requests locally.

Example
Clone https://github.com/amiinwani/free-exercise-db-with-videos and load the JSON exercise files directly; a demo API server is included in the repo for testing.

Use cases

  • Ship an offline workout app using the bundled exercise images and videos
  • Build a searchable exercise encyclopedia with video demonstrations
  • Prototype an exercise API on your own computer with the included demo server
