CoinLore

Dead-simple free crypto prices with zero setup

Open in PlugMyAgentOfficial docs

What it does

CoinLore is one of the simplest crypto APIs around: no key, no signup, just request tickers, global market stats, or exchange data and get JSON back. You can use it to power a basic price list on a website, to show global crypto market cap on a dashboard, or to grab a quick top-100-coins snapshot for analysis. It tracks thousands of coins and hundreds of exchanges, and the site simply asks you to keep requests to about one per second.

What you can do with it

  • Basic crypto price list on a website
  • Global market cap and dominance stats on a dashboard
  • Top-100-coins snapshot for quick analysis

Set it up

  1. No signup needed. Open the docs page at http://www.coinlore.com/cryptocurrency-data-api.
  2. Paste the example tickers URL into your browser to see live data.
  3. Adjust the start and limit parameters to page through all coins.
  4. Try the global stats endpoint for total market cap and Bitcoin dominance.
  5. Keep your app at one request per second to stay in good standing.

Example request

https://api.coinlore.net/api/tickers/?start=0&limit=100
