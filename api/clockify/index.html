Clockify

Time tracking API free forever

What it does

Clockify is a free-forever time tracker with a documented REST API for time entries, projects, and workspaces. API access is included on the free plan, which also supports a limited number of webhooks. Paid plans add more automations and controls.

What you can do with it

  • Log billable hours from your own project tools
  • Build timesheet reports for clients
  • Track time against projects from a CLI or bot

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Clockify ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Create a free Clockify account
  2. Open your profile settings and generate an API key
  3. Send the key as an X-Api-Key header in requests
  4. Create a workspace and project in the app first
  5. Start timers with POST /v1/workspaces/WORKSPACE_ID/time-entries
  6. Set up webhooks on paid tiers for real-time events
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.
