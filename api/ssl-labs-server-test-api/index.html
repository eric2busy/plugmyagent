SSL Labs Server Test API

Grade any website's HTTPS security from A to F, free.

What it does

Qualys SSL Labs runs the internet's best-known TLS/HTTPS checker, and its free API lets you programmatically test any public website's security configuration: certificate validity, supported protocols and ciphers, and known vulnerabilities. You kick off an assessment, poll until it finishes (it takes a minute or two), and get a detailed report with the famous A–F grade. Note that API v4 requires a one-time registration, and tests are rate-limited so you can't hammer it.

What you can do with it

  • Check whether your own website's HTTPS setup earns an A grade
  • Audit a client's site for expired certs or weak ciphers before a launch
  • Track TLS grades across a portfolio of sites over time

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for SSL Labs Server Test API ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Complete the one-time API v4 registration described in the docs.
  2. Start an assessment with /analyze?host=DOMAIN.
  3. Poll the same URL (add &fromCache=on after starting) until 'status' is READY.
  4. Read the 'grade' per endpoint and the details for anything below A.
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.
