Marketstack

Simple stock market data API with end-of-day prices

What it does

Marketstack is a straightforward API for historical and end-of-day stock data from exchanges around the world. You can use it to chart a stock's price history over the past year, to build a simple portfolio returns tracker, or to back-test a basic trading idea on daily data. The free plan only includes end-of-day data (no live intraday prices) and a small monthly request budget, so it suits casual tracking more than active trading.

What you can do with it

  • Chart a stock's price history over the last 12 months
  • Track portfolio returns with daily closing prices
  • Back-test a simple strategy on historical daily data

2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Sign up for a free account at marketstack.com.
  2. Copy your access key from the dashboard.
  3. Read the FAQ/docs to see which endpoints are free.
  4. Try the example EOD URL in your browser with your access key.
  5. Budget your ~100 monthly calls by requesting multiple symbols in one call.
