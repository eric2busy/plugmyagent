Oura API v2

Sleep, readiness, and recovery data from your Oura ring.

What it does

Oura's API v2 exposes sleep stages, readiness scores, recovery, workouts, heart data, and body measurements from the Oura ring. A sandbox mode provides synthetic data, so you can build and test without owning a ring. Registration is free and uses standard OAuth2 (personal access tokens were deprecated in December 2025).

What you can do with it

  • Correlate readiness scores with workouts and habits
  • Build a sleep-quality dashboard from your ring data
  • Prototype health apps with sandbox data before buying a ring

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Oura API v2 ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Create a free Oura developer account on the Oura Cloud portal.
  2. Register a new application with your name, website, and redirect URL.
  3. Note the client ID and client secret for your application.
  4. Send the user through the OAuth2 authorization flow.
  5. Use the access token to read sleep, readiness, activity, and session data.
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.
