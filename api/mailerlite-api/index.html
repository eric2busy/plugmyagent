MailerLite API

Manage subscribers, campaigns, and automations for your newsletter via API.

What it does

MailerLite's REST API covers subscribers, campaigns, automations, forms, and segments. You create a token in your account and call a clean, well-documented API. The free plan has shrunk over time, so check the current subscriber and send limits on their pricing page, but API access itself is available without paying. A solid pick for newsletter signup flows and drip campaigns.

What you can do with it

  • Add website signups to your MailerLite list in real time
  • Tag buyers differently from free-trial users automatically
  • Kick off a welcome email sequence the moment someone subscribes

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for MailerLite API ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Create a free MailerLite account and complete the approval steps
  2. Go to Integrations, then Developer API, and create a token
  3. Test listing subscribers to confirm the token works
  4. Add new subscribers from your signup forms via the API
  5. Trigger automations or add subscribers to groups as needed
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.
