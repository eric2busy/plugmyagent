PubNub

The realtime delivery network behind live chat, live tracking, and multiplayer. 200 free users.

What it does

PubNub is a global realtime network: you publish a message once and it appears instantly on every connected device. It's the backbone for chat apps, live location tracking, multiplayer games, and IoT dashboards. The free plan covers 200 monthly active users with presence (who's online), message history, and mobile push.

What you can do with it

  • Show live driver or delivery locations on a map
  • Sync game moves between players in real time
  • Push live scores, stock prices, or sensor readings to dashboards

2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Sign up and create a PubNub app
  2. Copy your publish and subscribe keys
  3. Install an SDK (JavaScript, Swift, Kotlin, Python, and more)
  4. Publish your first message to a channel and subscribe to receive it
  5. Turn on Access Manager to secure channels per user
