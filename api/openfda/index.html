OpenFDA

FDA data on drugs, devices, recalls, and adverse events.

What it does

openFDA is the FDA's official open API for data on drugs, medical devices, food recalls, and adverse events. An API key is optional. Anonymous requests work with lower daily limits. And keys are free with no card required. It is the authoritative source for medication labels, recall notices, and reported side effects.

What you can do with it

  • Check drug labels and reported side effects
  • Monitor FDA recalls for products you use
  • Research medications for a health app

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for OpenFDA ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Start calling endpoints immediately with no key to test.
  2. Request a free API key on the authentication docs page for higher limits.
  3. Add your key as the api_key query parameter.
  4. Query drug labels, adverse events, recalls, or device data.
  5. Cache responses where possible to stay within daily limits.
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.

Put it where the example above shows (usually an Authorization header or a key in the URL). FREE LIMIT: Free key: 240 requests/minute and 120,000/day; anonymous: 240/minute and 1,000/day TEST: once it's set up, ask it to look up one item you know. If you can't make web requests yourself, give me the exact curl command with my key filled in so I can run it. Docs if you get stuck: https://open.fda.gov/apis/authentication/

Keep API keys private. Only share yours with tools and people you trust.
