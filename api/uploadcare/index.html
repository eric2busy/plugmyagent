Uploadcare

File upload widget and CDN free for personal projects.

Open in PlugMyAgentOfficial docs

What it does

Uploadcare provides a file upload widget, upload API, image transformations, and a CDN for delivering files. The free plan includes 1,000 operations per month, files up to 500 MB, the upload widget and API, basic transformations, video streaming, signed uploads, and webhooks. One important catch: the free plan is for personal use only, so commercial projects need a paid plan. It is a quick way to add polished uploads to a side project.

What you can do with it

  • Add drag-and-drop file uploads to a personal project fast.
  • Store and serve user avatars or attachments through a CDN.
  • Resize and crop uploaded images with URL parameters.

Set it up

  1. Create a free Uploadcare account.
  2. Copy your public key from the dashboard.
  3. Add the upload widget script to your page with the public key.
  4. Let users pick files; Uploadcare returns a file UUID.
  5. Serve files through the CDN with optional transformation parameters.

Example request

curl -X POST https://upload.uploadcare.com/base/ -F "UPLOADCARE_PUB_KEY={public_key}" -F "UPLOADCARE_STORE=1" -F "file=@photo.jpg"
