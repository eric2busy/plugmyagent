Render

Free hosting for web apps and static sites

What it does

Render hosts web apps, APIs, and static sites from your Git repo with automatic deploys on every push. The free tier gives you 750 hours a month of web service time; free web services sleep after 15 minutes of inactivity and wake on the next visit. Static sites are free, never sleep, and include 100 GB of monthly bandwidth.

What you can do with it

  • Hosting hobby web apps and APIs
  • Free static site hosting with custom domains
  • Staging environments for projects

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Render ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. 1. Sign up at render.com (GitHub login works).
  2. 2. Click New > Web Service or Static Site and connect your repo.
  3. 3. Set the build command (e.g. npm install; npm run build) and start command.
  4. 4. Click Create. Render deploys and gives you a live URL with free SSL.
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.
