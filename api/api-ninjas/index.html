What it does

API Ninjas offers a library of over 90 simple APIs behind a single free key, including Exercises, Nutrition, and Calories Burned. You can get workout exercises filtered by muscle or difficulty, estimate the nutrition of any food phrase, or calculate calories burned for activities like running or yoga. The free plan is for noncommercial projects and requires crediting API Ninjas in your app.

What you can do with it

  • Build a workout planner that lists biceps exercises with instructions
  • Show calories burned for an activity based on body weight and minutes
  • Estimate nutrition from a food sentence like '1 lb brisket and fries'

Set it up

  1. Create a free account on api-ninjas.com to get your API key (no credit card).
  2. Add the key to every request as the X-Api-Key header.
  3. Pick an endpoint from the docs, e.g. /v1/exercises, /v1/nutrition, or /v1/caloriesburned.
  4. Add query filters like muscle=biceps or activity=skiing to get results.
  5. Include 'Data from API Ninjas' credit somewhere in your project.

Example request

curl -H 'X-Api-Key: YOUR_KEY' 'https://api.api-ninjas.com/v1/exercises?muscle=biceps'
