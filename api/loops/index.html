Loops

Email Free key (no card)

About

Loops is a modern email platform that handles marketing campaigns, lifecycle emails, and transactional mail (like receipts and password resets) from one API. Its free plan gives small projects real sending volume without a credit card. The API is simple: one endpoint for transactional sends, plus endpoints for contacts and events. Good for SaaS welcome flows and order emails.

Details

Free to start. You may need a free key, but no credit card.

Auth: Free key (no card)

Rate limit: Free plan with monthly contact and send limits; check the current pricing page for exact numbers.

Verified: 2026-09-13

Best for: email marketing transactional automation

Read the docs Back to catalog

Setup

  1. Create a free Loops account
  2. Create an API key in settings
  3. Create a transactional email template and note its ID
  4. Send a test email through the transactional endpoint
  5. Fire events from your app to trigger lifecycle campaigns
Sign up
Example
POST https://app.loops.so/api/v1/transactional with header Authorization: Bearer <token>, plus to, transactionalId, and dataVariables

Use cases

  • Send order confirmations and receipts from your store
  • Trigger a welcome series when someone creates an account
  • Send password-reset and notification emails via API
