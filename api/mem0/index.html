Mem0

Long-term memory for AI agents and chatbots

Open in PlugMyAgentOfficial docsGet free access

What it does

Mem0 gives your agent a memory that persists between sessions, so it remembers user preferences, facts, and context instead of starting blank every chat. The hosted Hobby plan is free with 10,000 memory adds per month and unlimited end users, no credit card required, and the core is open source if you would rather self-host.

What you can do with it

  • Agent long-term memory
  • Personalized chatbots
  • Remembering user preferences

Set it up

  1. 1. Sign up at app.mem0.ai and copy your API key from the dashboard.
  2. 2. Install the SDK with pip install mem0ai, or call the REST API directly.
  3. 3. Add memories tagged with a user_id, then search them inside your agent loop.

Example request

POST https://api.mem0.ai/v1/memories/ --header "Authorization: Token YOUR_API_KEY"
