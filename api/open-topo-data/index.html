Open Topo Data

Free elevation for any point on Earth. No signup.

What it does

Open Topo Data answers a simple question: how high is this spot? Give it one coordinate or a whole list and it returns elevation in meters from open terrain datasets like NASA's and the USGS's. The API speaks the same language as Google's old elevation API, so switching is easy.

What you can do with it

  • Check if your running route is hillier than last week's
  • Color a hiking map by elevation
  • Compare ground height across addresses for flood risk

Follow the quick-start steps

Use the provider's instructions below. There's no secret key to manage.

  1. 1. No signup. Call the public API directly.
  2. 2. Pick a dataset: srtm30m for most of the world, ned10m for the US.
  3. 3. Pass up to 100 locations at once, separated by pipes, e.g. locations=34.05,-118.24|35.68,139.69.
  4. 4. Stay under 1 call per second, or host your own copy with Docker for unlimited use.
