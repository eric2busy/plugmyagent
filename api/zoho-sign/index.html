Zoho Sign

E-signature API on a 14-day trial

What it does

Zoho Sign is Zoho's digital signature service with a REST API for sending documents and managing templates. It offers a 14-day trial for API access with a limited number of watermarked test documents. Some third-party documentation notes that production API use may require a paid account, so confirm current pricing.

What you can do with it

  • Automate NDA signing during vendor onboarding
  • Send sales contracts for signature from your CRM
  • Track signed document status in your own system

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Zoho Sign ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Sign up for Zoho Sign and start the 14-day API trial
  2. Register an application in the Zoho developer console
  3. Generate a grant token and exchange it for access and refresh tokens
  4. Request the ZohoSign scopes for documents and templates
  5. Call endpoints such as /sign/v1/documents with the OAuth token
  6. Test with the included watermarked documents before buying a plan
