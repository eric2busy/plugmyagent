Alpha Vantage

Free API key for stock prices, fundamentals, and technical indicators

What it does

Alpha Vantage is a market data service that hands out a free API key you can use to look up stock prices, company financials, currency rates, and built-in technical indicators like moving averages. You can use it to build a personal stock dashboard that shows daily price history, to screen companies by metrics such as price-to-earnings ratio, or to pull forex rates for a currency converter. The free tier is genuinely usable for side projects, though the daily request cap is tight.

What you can do with it

  • Personal stock price dashboard or watchlist
  • Company screener using P/E ratio and other fundamentals
  • Currency converter with forex rates

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Alpha Vantage ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Go to https://www.alphavantage.co/support/#api-key and fill in the short form to claim your free API key (no credit card needed).
  2. Check your email and copy the key they send you.
  3. Open the docs at https://www.alphavantage.co/documentation/ and pick an endpoint like TIME_SERIES_DAILY.
  4. Paste the example URL into your browser, swapping in your own key and a ticker like AAPL.
  5. Spread your requests through the day so you stay under the 25-per-day free limit.
