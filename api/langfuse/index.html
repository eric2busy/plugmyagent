About

Langfuse traces every prompt, completion, and tool call your agent makes, with cost, latency, and quality scores in one dashboard. The Cloud Hobby tier is free for 50,000 events a month with no card required, and the whole stack is MIT licensed so you can self-host it free.

Details

Free to start. You may need a free key, but no credit card.

Setup

  1. Create a free account at cloud.langfuse.com and start a project.
  2. Copy the public and secret keys from project settings.
  3. Install the Python or JS SDK and wrap your LLM calls; traces show up in seconds.
Sign up
Example
POST https://cloud.langfuse.com/api/public/ingestion --header "Authorization: Basic YOUR_KEYS"
