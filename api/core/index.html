What it does

CORE aggregates open-access research papers from repositories and journals around the world into one searchable API. You can search titles and full text, get download links, and explore citation data. A free API key is available for personal and noncommercial academic use; companies need a separate license.

What you can do with it

  • Search millions of open-access papers by keyword and get full-text links
  • Build a literature-review tool that pulls papers across all disciplines
  • Track new open-access publications on a research topic automatically

Set it up

  1. Sign up for a free API key on the CORE API services page (personal/academic use).
  2. Copy your key and send it as a Bearer token in the Authorization header.
  3. Paste the example request with your key to test a search.
  4. Explore the docs for works, journals, and download endpoints.

Example request

curl -H 'Authorization: Bearer YOUR_KEY' 'https://api.core.ac.uk/v3/search/works?q=machine+learning'
