About

Xero is cloud accounting software with a well-documented REST API for invoices, contacts, and payroll. Developers can sign up for a free developer account that includes a demo company for building and testing. Production connections require a paid Xero subscription.

Setup

  1. Sign up for a free Xero developer account
  2. Create an app in the developer portal to get a client ID and secret
  3. Connect the app to your demo company with OAuth 2.0
  4. Store the access and refresh tokens for your integration
  5. Call endpoints like /api.xro/2.0/Invoices with the token and tenant ID
  6. Use the demo company for all development and testing

Example
GET https://api.xero.com/api.xro/2.0/Invoices with headers Authorization: Bearer ACCESS_TOKEN and xero-tenant-id: TENANT_ID

Use cases

  • Sync ecommerce orders into accounting invoices
  • Reconcile payments against bank transactions
  • Build cash-flow dashboards from live ledger data
