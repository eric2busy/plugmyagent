Stadia Maps

Map tiles, geocoding, and routing from a privacy-friendly provider.

What it does

Stadia Maps offers map tiles, address search, and routing with a focus on privacy. No ad tracking baked into the maps. The free tier is meant for development, testing, school, and non-commercial projects. When your monthly credits run out, requests simply stop instead of billing you.

What you can do with it

  • Prototype a map feature without touching a credit card
  • Add address search to a school project
  • Get driving directions for a weekend project

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Stadia Maps ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. 1. Create a free Stadia Maps account. New accounts start with a trial, then drop to the free plan.
  2. 2. Copy your API key from the dashboard.
  3. 3. Use it as ?api_key=YOUR_KEY in tile, geocode, or routing URLs.
  4. 4. Watch the dashboard alerts so you know before you hit your monthly credit limit.
