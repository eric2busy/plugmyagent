TimeZoneDB

What time is it there? Exact answers by place, coordinates, or IP.

What it does

TimeZoneDB converts any city, coordinates, or IP address into the correct local time, UTC offset, and daylight-saving status. It answers unlimited queries at a polite pace, and the free key is only asked for personal or non-commercial use. The API also lists every time zone in the world for reference.

What you can do with it

  • Show 'your time / their time' on a meeting scheduler
  • Convert flight arrival times to the traveler's home zone
  • Stamp user activity with the correct local time

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for TimeZoneDB ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. 1. Register for a free TimeZoneDB account and copy your API key.
  2. 2. Call get-time-zone with by=position plus lat/lng. Or by=city, by=zone, or by=ip.
  3. 3. Read local time from formatted, and the offset from gmtOffset.
  4. 4. Keep requests to one per second; cache time zone lookups since they rarely change.
3
