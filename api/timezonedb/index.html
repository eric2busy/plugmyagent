About

TimeZoneDB converts any city, coordinates, or IP address into the correct local time, UTC offset, and daylight-saving status. It answers unlimited queries at a polite pace, and the free key is only asked for personal or non-commercial use. The API also lists every time zone in the world for reference.

Setup

  1. Register for a free TimeZoneDB account and copy your API key.
  2. Call get-time-zone with by=position plus lat/lng. Or by=city, by=zone, or by=ip.
  3. Read local time from formatted, and the offset from gmtOffset.
  4. Keep requests to one per second; cache time zone lookups since they rarely change.

Example
https://api.timezonedb.com/v2.1/get-time-zone?key=YOUR_KEY&format=json&by=position&lat=34.05&lng=-118.24

Use cases

  • Show 'your time / their time' on a meeting scheduler
  • Convert flight arrival times to the traveler's home zone
  • Stamp user activity with the correct local time
