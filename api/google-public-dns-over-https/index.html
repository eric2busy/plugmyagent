Google Public DNS over HTTPS

Google's free JSON API for DNS lookups with DNSSEC validation.

What it does

Google Public DNS offers a web-friendly DNS API that answers plain GET requests with JSON. No binary DNS knowledge required. It supports every record type (A, MX, TXT, and more) and can validate DNSSEC signatures for you, which is handy for security checks. Like Cloudflare's version, it's free, needs no key, and works from any browser or script.

What you can do with it

  • Fetch a domain's TXT records to verify email security (SPF/DKIM) setups
  • Add DNSSEC-validated lookups to a domain-research tool
  • Use as a fallback resolver alongside Cloudflare's for reliability

Follow the quick-start steps

Use the provider's instructions below. There's no secret key to manage.

  1. No signup needed. Just call the endpoint.
  2. Request https://dns.google/resolve?name=DOMAIN&type=RECORDTYPE in a browser or script.
  3. Add '&cd=1&do=1' if you want DNSSEC validation details in the response.
  4. Parse the 'Answer' array; 'Status: 3' means the domain doesn't exist.
