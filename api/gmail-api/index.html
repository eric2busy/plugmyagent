Gmail API

Read, search, and send your own Gmail programmatically. Free with any Google account.

What it does

The Gmail API lets you do almost anything Gmail's website can do, from your own code: read messages, search your inbox, organize with labels, and send email as yourself. It's free with any Google account. You just authorize access through your own Google login. Perfect for personal automation like auto-filing receipts or backing up important emails.

What you can do with it

  • Auto-sort incoming invoices into labels and save attachments to Drive
  • Build a personal daily digest of your most important unread emails
  • Send form submissions or alerts from your own Gmail address via automation

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Gmail API ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Go to console.cloud.google.com and create a free project
  2. Enable the Gmail API in APIs & Services → Library
  3. Create OAuth credentials (Desktop app type) and download the credentials file
  4. Follow Google's quickstart for your language to log in once and save access
  5. Run a list-messages call to see your inbox come back as data
