UK Parliament Members API

Every UK MP and Lord, searchable.

What it does

Search and retrieve UK Members of Parliament and Lords. Profiles, constituencies, party, and contact details. Free with no key. Parliament also runs separate official APIs for bills, committees, Hansard debates, votes, and questions if you need more.

What you can do with it

  • Find your MP by name or constituency
  • Build a contact-your-representative tool
  • Track parliament membership changes
