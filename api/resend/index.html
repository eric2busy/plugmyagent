What it does

Resend is a modern email-sending service built for developers but easy enough for anyone building a website or automation. You get an API key, and with one web request your app can send welcome emails, receipts, password resets, or alerts. The free tier covers 3,000 emails a month (up to 100 a day) without a credit card, which is plenty for most side projects and small businesses.

What you can do with it

  • Send order confirmations and password-reset emails from your website
  • Get email alerts from a script when something important happens
  • Send a small newsletter (up to ~3,000/month) without paying

Set it up

  1. Sign up free at resend.com (no credit card asked)
  2. In the dashboard, go to API Keys and click Create API Key
  3. Copy the key. It starts with re_
  4. Test with their test address onboarding@resend.dev first (no domain setup needed)
  5. To send from your own domain later, add their DNS records and verify the domain in the dashboard

Example request

POST https://api.resend.com/emails with {"from": "you@domain.com", "to": "friend@example.com", "subject": "Hi", "text": "Hello!"}
