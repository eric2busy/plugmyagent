What it does

urlscan.io visits a URL in a sandboxed browser and records everything: the page screenshot, every network request, cookies, redirects, and the technologies the site uses. Its API lets you search millions of past scans (someone may already have scanned that sketchy link) and submit new scans of your own. A free account gives you a key with per-action quotas; anonymous search is also possible at lower limits.

What you can do with it

  • Check whether a link in a suspicious email is a phishing page before clicking
  • See all the third-party trackers a website loads
  • Research phishing kits by searching scans of known-bad domains

Set it up

  1. Create a free account on urlscan.io and copy your API key from Settings & API.
  2. Search existing scans first. A prior sighting is free and costs no scan quota.
  3. To scan something new, POST the URL to /api/v1/scan/ with your API-Key header.
  4. Poll the returned result URL until the scan finishes, then read the verdict and screenshot.

Example request

https://urlscan.io/api/v1/search/?q=domain:example.com (add 'API-Key: YOUR_KEY' header for higher limits)
