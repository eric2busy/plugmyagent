About

LiveKit is an open-source video and audio platform that lets you add video rooms, voice chat, live captions, and even voice AI agents to your app. Its free Build plan includes 5,000 participant-minutes, 1,000 agent-session minutes, 50 GB of data transfer, and up to 100 people connected at once every month. Because the code is open source, you can also host it yourself for free.

Setup

  1. Create a free LiveKit Cloud account and project
  2. Copy your API key, secret, and project URL from the dashboard
  3. Create a room from the dashboard or with one API call
  4. Add the JavaScript, Swift, or Flutter SDK to your app and join the room with a token
  5. Upgrade or self-host when you outgrow the free allowances

Example
Create a room: POST https://your-project.livekit.cloud/twirp/livekit.RoomService/CreateRoom

Use cases

  • Build an AI voice assistant that talks to users over a live call
  • Add video rooms and live captions to a collaboration tool
  • Prototype a multiplayer voice-chat feature for a game or community app
