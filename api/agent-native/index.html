About

Agent-Native is a framework for building apps where the agent and the on-screen interface share the same actions, data, and state. Anything a person can do in the app, the agent can do too, because both sides call the same definitions. One action can be reached from the interface, the agent, an HTTP call, the command line, MCP, or agent-to-agent messages.

Setup

  1. Install Node.js if you do not have it yet
  2. Run the create command to scaffold a chat-style agent
  3. Add your model key, from Builder.io, Anthropic, OpenAI, or a local Ollama model
  4. Define an action once and try it from both the interface and the agent
  5. Run the app and watch both sides stay in sync
Sign up
Example
npx --yes @agent-native/core@latest create my-agent --standalone --template chat

Use cases

  • Build an app where users and agents work the same tasks together
  • Give an agent the same buttons and tools a person gets
  • Ship one action that works over chat, HTTP, and MCP at once
