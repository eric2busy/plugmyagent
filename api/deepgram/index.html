Deepgram

$200 free credit for speech-to-text and voice AI

What it does

Deepgram turns speech into text with very high accuracy and low delay, and also powers voice agents that can listen and talk. New accounts get $200 in free credit with no credit card required. You send audio to their API and get back a transcript with timestamps, speaker labels, and more.

What you can do with it

  • Transcribing meetings and interviews
  • Building voice agents and phone bots
  • Adding voice input to apps

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Deepgram ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. 1. Sign up at console.deepgram.com.
  2. 2. Create a project and generate an API key.
  3. 3. Send audio to https://api.deepgram.com/v1/listen with Authorization: Token YOUR_KEY.
  4. 4. Add query options like ?diarize=true for speaker labels or ?punctuate=true.
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.

Set up Deepgram for me so you can use it. HOW TO CALL IT curl -X POST https://api.deepgram.com/v1/listen --header "Authorization: Token PASTE_KEY_HERE" --data-binary @audio.mp3 AUTH: free API key. Mine: PASTE_KEY_HERE. Put it where the example above shows (usually an Authorization header or a key in the URL). FREE LIMIT: $200 signup credit (no card); usage deducts from credit balance. TEST: once it's set up, ask it to fetch one small thing, like a repo or a fresh UUID. If you can't make web requests yourself, give me the exact curl command with my key filled in so I can run it. Docs if you get stuck: https://developers.deepgram.com/docs

Keep API keys private. Only share yours with tools and people you trust.
