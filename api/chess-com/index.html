Chess.com

Player profiles, game archives, leaderboards, and the daily puzzle.

What it does

Chess.com's published-data API opens up public chess data: player profiles and stats, full monthly game archives with move lists, titled-player lists, country leaderboards, club info, and the daily puzzle. Everything is free with no key - just don't fire off lots of requests in parallel.

What you can do with it

  • A chess stats dashboard for your club
  • Analyzing your own game history
  • Leaderboards and player profiles in a chess app

  2. Get a profile: https://api.chess.com/pub/player/magnuscarlsen.
  3. Get monthly games: https://api.chess.com/pub/player/magnuscarlsen/games/2026/08.
  4. Try the daily puzzle: https://api.chess.com/pub/puzzle.
  5. No key needed - just be polite with request volume.
