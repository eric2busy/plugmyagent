Tomorrow.io

Minute-by-minute weather built for app developers.

What it does

Tomorrow.io is a modern weather company that sells data to big apps. But it also keeps a genuinely useful free tier. You get current conditions, forecasts, and air quality for any location, all in a clean, well-documented API. The company even has a public support site that spells out exactly what the free plan allows.

What you can do with it

  • Add rain-now awareness to a daily driver app
  • Show hourly temperature for the next 5 days
  • Pull air quality data for a health tracker

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Tomorrow.io ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. 1. Create a free Tomorrow.io account and generate an API key.
  2. 2. Pick an endpoint: /v4/weather/realtime for right now, /v4/weather/forecast for the future.
  3. 3. Pass your location as coordinates or a place name with the apikey parameter.
  4. 4. Watch your usage. 500 calls a day is plenty if you cache results instead of re-asking.
3
