What it does

Strava is one of the most popular fitness apps, and its API lets you read and create activities such as runs, rides, and swims. You can pull detailed streams like GPS, heart rate, and pace, plus list routes, segments, and gear. It is the easiest way to get your own workout data out of the Strava ecosystem for dashboards and automation.

What you can do with it

  • Pull your workouts into a personal training dashboard
  • Auto-log runs and rides to a spreadsheet or habit tracker
  • Analyze pace, power, and heart-rate trends over time

Set it up

  1. Create a free Strava account if you do not have one.
  2. Go to the Strava developer portal and register a new application with a name, website, and callback URL.
  3. Note the client ID and client secret shown for your app.
  4. Send the athlete to Strava's authorization page to grant your app permission.
  5. Exchange the returned authorization code for an access token, then include it in API requests.

Example request

GET https://www.strava.com/api/v3/athlete/activities?per_page=10 with your access token in the Authorization header
