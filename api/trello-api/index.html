Trello API

Manage your Trello boards, cards, and lists from anywhere. Free with a Trello account.

What it does

Trello's API lets you create cards, move them between lists, add comments, and pull board data into other tools. Everything you can do by dragging cards around, but automatic. It's free for all Trello users. A classic use: every new sale, support ticket, or form submission becomes a card on the right board without anyone touching it.

What you can do with it

  • Turn every new order or support email into a Trello card automatically
  • Build a kanban dashboard that updates itself from your other tools
  • Archive finished cards or nudge stale ones with a scheduled script

Set it up

  1. Visit trello.com/app-key while logged in and copy your API key
  2. On the same page, click the Token link and authorize to get your token
  3. Keep the token private. It's like a password for your Trello
  4. Test with: https://api.trello.com/1/members/me/boards?key=YOUR_KEY&token=YOUR_TOKEN
  5. Use the card endpoints to create cards, move them between lists, or add checklists

Example request

GET https://api.trello.com/1/members/me/boards?key={key}&token={token}
