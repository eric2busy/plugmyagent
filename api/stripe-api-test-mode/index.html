Stripe API Test Mode

Build and test real payment flows with fake cards, free

What it does

Stripe gives every account a test mode where you can create charges, subscriptions, and payment links using fake card numbers, without moving real money. You can use it to build a checkout page and test success and failure paths, to prototype a subscription billing flow, or to learn how webhooks confirm payments. Testing is completely free; Stripe only charges its transaction fee when you switch to live payments with real cards.

What you can do with it

  • Build a checkout page and test card declines safely
  • Prototype subscription billing and trial periods
  • Learn how payment webhooks confirm successful charges

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Stripe API Test Mode ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Create a free Stripe account at stripe.com (no card needed for test mode).
  2. In the dashboard, make sure Test mode is toggled on and copy your test secret key.
  3. Try the example curl charge with a test token like tok_visa to simulate a Visa payment.
  4. Use the dashboard's test clock or webhooks view to watch the payment event arrive.
  5. When ready, complete Stripe's activation to switch the same code to live mode.
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.

Set up Stripe API Test Mode for me so you can use it. Your test secret key goes as the Basic Auth username: -u sk_test_PASTE_KEY_HERE: (blank password). FREE LIMIT: Test mode is free; requests are rate-limited. See Stripe's published rate-limit docs TEST: once it's set up, ask it: “what's the price of Bitcoin in USD?”. Keep API keys private. Only share yours with tools and people you trust.
