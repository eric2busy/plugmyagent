About

OVHcloud's AI Endpoints let you call 20-plus open-weight models through an OpenAI-compatible API, and the anonymous lane needs no signup, no key, and no card: just send a request (2 per minute per IP per model). It is the only truly keyless lane in this sweep, and it is hosted in Europe, which keeps it friendly for GDPR-minded projects.

Details

No key needed. You can call it right away.

Setup

  1. Open the AI Endpoints getting-started guide linked above.
  2. Copy the endpoint URL for the model you want (Llama, Qwen, Mistral, and more).
  3. POST an OpenAI-format chat request to it. No signup or key needed.
  4. If you need more speed later, create an OVHcloud project for authenticated keys.
