Freshsales

Freshworks CRM with free-trial API access

What it does

Freshsales is the Freshworks sales CRM with a free plan for unlimited users on basic features. Its documented REST API covers contacts, deals, accounts, and activities. Note: some third-party comparisons report that API access may require a Pro plan, so confirm on the current Freshworks pricing page before relying on free-plan API access.

What you can do with it

  • Push new signups into the sales pipeline
  • Score and route leads from landing pages
  • Log calls and emails against contact records

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Freshsales ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Sign up for Freshsales, starting on the free plan or a trial
  2. Open your profile settings to find your API key
  3. Copy your account subdomain, which is part of every API URL
  4. Authenticate requests with the API key in the Authorization header
  5. Call the /api/contacts and /api/deals endpoints
  6. Monitor usage against the published call limits
