Regulations.gov API

Search federal rules, dockets, and public comments as they're being made.

What it does

When federal agencies propose a new rule, they post the docket and invite public comments on Regulations.gov, and this API lets you search those documents and comments programmatically. You can find every comment submitted on a proposed rule, pull rule text, and monitor dockets over time. A free api.data.gov key gets you 1,000 requests an hour.

What you can do with it

  • Monitor new rules affecting your industry and read what the public said
  • Analyze public comment sentiment on a controversial proposed rule
  • Build a watchlist app that emails you when a docket updates

Set it up

  1. Sign up for a free api.data.gov key and wait for the confirmation email.
  2. Search for a docket on regulations.gov to grab its ID.
  3. Call the /v4/comments or /v4/documents endpoint with filter parameters and your key.
  4. Step through pages of results to pull full comment sets.

Example request

https://api.regulations.gov/v4/comments?filter[commentOnId]=0900006485cb5ec7&api_key=YOUR_KEY
