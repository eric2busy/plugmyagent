n8n

The free, self-hosted Zapier alternative with 1,500+ integrations and no per-task fees.

What it does

n8n is a visual workflow-automation tool you can run on your own computer or server for free. No limits on how many automations you run, because you own the machine. It connects 1,500+ apps (Gmail, Slack, Notion, Stripe, and more), lets you drop in JavaScript or Python when you need custom logic, and has a huge library of ready-made workflow templates. Fair-code license, very active community.

What you can do with it

  • Auto-save email attachments to Drive and log them in a spreadsheet
  • Post a Slack message whenever a new row appears in your database
  • Build multi-step business workflows (lead → CRM → email → task) for free

Follow the quick-start steps

Use the provider's instructions below. There's no secret key to manage.

  1. Install Node.js, then run: npx n8n (or use the Docker command from their docs)
  2. Open http://localhost:5678 in your browser to see the workflow editor
  3. Click to create a workflow and add a trigger (e.g. a webhook or schedule)
  4. Add app nodes. Connect Gmail, Slack, or anything else by signing in once per app
  5. Hit Execute to test, then flip the workflow Active and it runs on its own
