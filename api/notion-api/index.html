Notion API

Read and write your Notion pages and databases from any app. Free with a Notion account.

What it does

Notion's official API lets your tools talk directly to your Notion workspace: create pages, add rows to databases, pull tasks, and sync information automatically. It's free with any Notion plan. If you already organize your life or business in Notion, this turns it into the hub that everything else feeds into.

What you can do with it

  • Automatically log completed tasks or form entries into a Notion database
  • Build a personal dashboard that pulls tasks from Notion
  • Sync bookings or orders from your business tools into your Notion CRM

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Notion API ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Go to notion.so/my-integrations and click New integration
  2. Name it, pick your workspace, and copy the Internal Integration Token (starts with ntn_)
  3. Open the Notion page or database you want to use and add your integration under Connections
  4. In the API, use the page or database ID from the Notion URL
  5. Try creating a test page or reading a database to confirm the connection
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.

Your token goes in the Authorization header as: Bearer <redacted> (plus a Notion-Version header). FREE LIMIT: Free; about 3 requests per second. Plenty for personal and small-business use TEST: once it's set up, have it create an item called “plugmyagent test”, then delete it. Keep API keys private. Only share yours with tools and people you trust.
