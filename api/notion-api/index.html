What it does

Notion's official API lets your tools talk directly to your Notion workspace: create pages, add rows to databases, pull tasks, and sync information automatically. It's free with any Notion plan. If you already organize your life or business in Notion, this turns it into the hub that everything else feeds into.

What you can do with it

  • Automatically log completed tasks or form entries into a Notion database
  • Build a personal dashboard that pulls tasks from Notion
  • Sync bookings or orders from your business tools into your Notion CRM

Set it up

  1. Go to notion.so/my-integrations and click New integration
  2. Name it, pick your workspace, and copy the Internal Integration Token (starts with ntn_)
  3. Open the Notion page or database you want to use and add your integration under Connections
  4. In the API, use the page or database ID from the Notion URL
  5. Try creating a test page or reading a database to confirm the connection

Example request

POST https://api.notion.com/v1/pages
