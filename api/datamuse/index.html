About

Datamuse is a word-finding engine: give it a word and get rhymes, synonyms, antonyms, words that sound alike, or words described by a phrase. Great for lyricists, poets, crossword lovers, and word games. Free, no key.

Setup

  1. Read the docs at https://www.datamuse.com/api/.
  2. Rhymes: https://api.datamuse.com/words?rel_rhy=orange.
  3. Synonyms: https://api.datamuse.com/words?rel_syn=happy.
  4. Sounds like: https://api.datamuse.com/words?sl=persuade.
  5. Describe with a phrase: https://api.datamuse.com/words?ml=ringing+in+the+ears.
