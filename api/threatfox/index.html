ThreatFox

Check whether an IP, domain, or URL is a known malware threat.

What it does

ThreatFox is a free community database run by the Swiss nonprofit abuse.ch that collects 'indicators of compromise'. Technical fingerprints (bad IP addresses, domains, URLs, and file hashes) tied to malware and cyberattacks. Its API lets you look up any suspicious indicator and see which malware family it belongs to and who reported it. You need a free unified abuse.ch auth key, which takes minutes to get.

What you can do with it

  • Look up a suspicious IP from your router logs to see if it's known malware infrastructure
  • Enrich security alerts with malware-family names automatically
  • Build a blocklist feed of recently reported malicious domains

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for ThreatFox ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Register for a free Auth-Key at auth.abuse.ch.
  2. Send HTTP POST requests to https://threatfox-api.abuse.ch/api/v1/ with an Auth-Key header.
  3. Use the search_ioc query with the IP, domain, URL, or hash you want to check.
  4. Read the 'malware' and 'confidence_level' fields in the JSON to judge the threat.
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.
