Crisp

Live chat API with a free forever plan

Open in PlugMyAgentOfficial docsGet free access

What it does

Crisp is a customer messaging platform with a $0 free plan and a 14-day trial of paid features. Its REST API and developer docs cover conversations, contacts, and website settings. Developer testing tokens have lower limits than production keys, so check the token types before scaling.

What you can do with it

  • Pull support conversations into an internal dashboard
  • Automate visitor follow-ups based on chat events
  • Sync contact profiles with your CRM

Set it up

  1. Sign up for a free Crisp account
  2. Open Settings > Integrations > API to create a plugin
  3. Generate your REST API identifier and key
  4. Use a developer testing token while building
  5. Call endpoints like /v1/website/WEBSITE_ID/conversations with basic auth
  6. Upgrade to a production token before launching

Example request

GET https://api.crisp.chat/v1/website/WEBSITE_ID/conversations/1 with basic auth IDENTIFIER:KEY
