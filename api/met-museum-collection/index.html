Met Museum Collection

Images & Media No key

About

The Metropolitan Museum of Art's collection API covers more than 470,000 objects, from ancient artifacts to modern art, with no key and no signup. You can search by keyword, department, or date range, and many objects include public-domain images. It pairs naturally with the Art Institute of Chicago entry for a two-museum art brain.

Details

No key needed. You can call it right away.

Auth: No key

Rate limit: No key, no signup; keep request volume reasonable

Verified: 2026-09-22

Best for: personal fun

Read the docs Back to catalog

Setup

  1. No account or key is needed.
  2. Search the collection endpoint with a keyword.
  3. Fetch full object details by object ID.
  4. Use primaryImage URLs for objects marked public domain.
Sign up
Example
GET https://collectionapi.metmuseum.org/public/collection/v1/search?q=sunflowers

Use cases

  • Build a museum-tour bot that describes objects on request
  • Post a random artwork with its story every day
  • Research art history topics with real collection data
