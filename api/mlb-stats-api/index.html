MLB Stats API

Official Major League Baseball stats, schedules, and live scores. Free, no key required.

What it does

Major League Baseball publishes its own stats API with schedules, live and final scores, box scores, player stats, standings, rosters, and league leaders. All free and unauthenticated. It powers MLB's own apps and sites, so the data is first-party and dependable. Community docs fill the gap where MLB hasn't published official documentation.

What you can do with it

  • Put a live scoreboard of today's games on your website or bar TV dashboard
  • Build a fantasy-baseball helper that pulls player stats and probable pitchers
  • Add a standings table to a fan page that updates itself every day
