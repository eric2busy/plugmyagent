What it does

The Google Calendar API gives your apps and scripts full control over Google Calendar: create events, invite people, check who's free, and get alerts when things change. It's free for any Google account and is the backbone of countless booking tools, assistants, and automations. If it happens in a calendar, this API can do it.

What you can do with it

  • Auto-create calendar events from form submissions or emails
  • Build a 'when is everyone free?' checker for your team or family
  • Get webhook alerts the moment a meeting is added or moved

Set it up

  1. Create a free project at console.cloud.google.com
  2. Enable the Google Calendar API in APIs & Services → Library
  3. Create OAuth credentials and download them
  4. Walk through Google's official quickstart in your preferred language to authorize
  5. Try creating an event through the API and watch it appear in your calendar

Example request

POST https://www.googleapis.com/calendar/v3/calendars/primary/events
