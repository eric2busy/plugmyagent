iNaturalist

200M+ wildlife sightings with photos, from citizen scientists worldwide.

Open in PlugMyAgentOfficial docs

What it does

iNaturalist is a citizen-science platform where people record wildlife sightings with photos, sounds, and locations. Its free API gives you access to over 200 million observations, species data, identifications, and projects. Reading public data needs no key; only posting observations or accessing private data requires OAuth.

What you can do with it

  • Show recent bird or insect sightings near a location on a nature map
  • Build a species-identification helper using community-verified photos
  • Track biodiversity trends for a school or conservation project

Set it up

  1. Paste the example URL into your browser to see observations instantly, no signup needed.
  2. Change taxon_name to any species, or add place_id and date filters.
  3. Explore the full endpoint list in the interactive docs page.
  4. Only if you need to post data: register an app for OAuth credentials.

Example request

https://api.inaturalist.org/v1/observations?taxon_name=Apis%20mellifera&per_page=3
