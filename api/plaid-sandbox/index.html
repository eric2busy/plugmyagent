Plaid Sandbox

Free test bank data for fintech apps, no real accounts needed

What it does

Plaid's Sandbox is a free, fully-featured test environment that simulates linking bank accounts and pulling transactions, balances, and identity data. You can use it to prototype a budgeting app with realistic fake transactions, to test a bank-linking flow before launch, or to explore Plaid's API responses without writing code via Sandbox Studio. Sandbox keys are free from the Plaid dashboard, and test logins like user_good work with every fake institution.

What you can do with it

  • Prototype a budgeting app with realistic fake transactions
  • Test a bank-account linking flow end to end
  • Explore API responses with no code in Sandbox Studio

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Plaid Sandbox ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Create a free Plaid account and open the dashboard to find your client_id and Sandbox secret.
  2. Read the sandbox overview at https://plaid.com/docs/sandbox/.
  3. Run the example curl call to create a sandbox public token.
  4. Exchange the public token for an access token, then call the transactions endpoint.
  5. Or skip the code entirely and experiment in Sandbox Studio from the dashboard.
