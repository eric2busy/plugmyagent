Cloudflare D1

SQLite database at the edge, free on Workers plan

What it does

Cloudflare D1 is a database built on SQLite that runs across Cloudflare's global network, right next to your serverless code. It's included free on the Workers Free plan: when you hit the daily limit, queries simply pause instead of charging you. You write plain SQL and it feels like a tiny local database with global reach.

What you can do with it

  • Databases for serverless apps
  • Small apps that need global low latency
  • SQLite-backed APIs on Cloudflare Workers

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Cloudflare D1 ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. 1. Sign up free at cloudflare.com.
  2. 2. Install Wrangler: npm install -g wrangler, then run wrangler login.
  3. 3. Create a database: wrangler d1 create my-db.
  4. 4. Bind it to a Worker in wrangler.toml and query it with SQL.
