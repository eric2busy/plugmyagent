About

open-multi-agent is an open-source TypeScript framework for running teams of agents with durable run records, human-approval checkpoints, and verifiable audit trails. A single command scaffolds a starter app, and the demo runs with no API key. It is built for agent systems you have to trust: every step is recorded and checkable.

Setup

  1. Run npm create oma-app@latest to scaffold a starter.
  2. Open the project and run the demo (no API key needed).
  3. Define your agent team and add human-approval checkpoints.
  4. Plug in your model API key and run your first multi-agent workflow.

Use cases

  • Ship multi-agent workflows in TypeScript
