About

DiceBear turns any seed (a username, email, or any text) into a unique cartoon avatar in dozens of styles: pixel art, cute faces, robots, identicons, and more. The same seed always produces the same avatar, so each user gets a consistent identity. The shared public API is free, and if you ever outgrow it you can run it yourself with their open-source Docker image.

Setup

  1. Pick a style from the playground on dicebear.com
  2. Paste the example URL into a browser, swapping JohnDoe for any name
  3. Change the style name (e.g., personas, adventurer, bottts) to restyle it
  4. Use the URL directly as an image source on your site or app
Sign up
Example
https://api.dicebear.com/7.x/pixel-art/svg?seed=JohnDoe

Use cases

  • Give every user of an app or forum an automatic profile picture
  • Create consistent placeholder avatars for mockups and presentations
  • Generate team member icons for a project dashboard without design work
