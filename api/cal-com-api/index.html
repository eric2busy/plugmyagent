Cal.com API

The free, open-source Calendly alternative. Bookable links and scheduling you can control with an API.

What it does

Cal.com is the open-source answer to Calendly: free scheduling pages where people can book meetings with you. Its API lets you create event types, check available time slots, and manage bookings programmatically. You can even self-host the whole thing for free forever, or use their hosted free tier.

What you can do with it

  • Build a booking system for a barbershop, salon, or consulting business
  • Sync bookings into your own CRM or spreadsheet automatically
  • Embed 'book a call' slots inside your own website or app

Set it up

  1. Sign up free at cal.com and set up your first event type (e.g. '30-min consultation')
  2. Go to Settings → Developer → API Keys and generate a key (starts with cal_live_)
  3. Test by fetching your available slots with the API docs example
  4. Embed your cal.com link on your website for people to book
  5. Use webhooks to get pinged whenever someone books or cancels

Example request

GET https://api.cal.com/v2/slots?eventTypeId=123&start=2026-09-14
