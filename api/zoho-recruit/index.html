Zoho Recruit

Business Operations Free trial

About

Zoho Recruit is an applicant tracking system with a free plan and a 15-day trial of its higher tiers. Its APIs support job openings, candidates, interviews, and clients via OAuth. API limits scale with the plan, so production usage may need a paid tier.

Setup

  1. Sign up for a free Zoho Recruit account
  2. Register an application in the Zoho developer console
  3. Generate a grant token and exchange it for access and refresh tokens
  4. Request scopes for Recruit modules such as candidates and job openings
  5. Call the Recruit API v2 endpoints with the OAuth token
  6. Check your plan's API limits before scaling automation
Sign up
Example
GET https://recruit.zohoapis.com/recruit/v2/Candidates with header Authorization: Zoho-oauthtoken ACCESS_TOKEN

Use cases

  • Post jobs and collect applications from your careers page
  • Sync candidate pipelines with interview scheduling
  • Report on time-to-hire from recruiting data
