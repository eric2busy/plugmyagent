Auth0

Enterprise-grade login free for up to 25,000 monthly users.

What it does

Auth0 by Okta is a hosted authentication platform that adds login, signup, social sign-in, and passwordless to any app through SDKs and APIs. The free plan needs no credit card and covers up to 25,000 monthly active users, one custom domain, unlimited social connections, passwordless login, five organizations, and one enterprise connection. The Management API lets you automate user, role, and tenant administration. It is the most feature-complete free auth tier available.

What you can do with it

  • Add secure login with social and passwordless options to any app.
  • Manage multiple customer organizations with separate logins.
  • Automate user provisioning and role assignment via the Management API.

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Auth0 ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Sign up free at auth0.com with no credit card.
  2. Create an application and choose your tech stack.
  3. Configure allowed callback URLs for your app.
  4. Install the Auth0 SDK for your framework.
  5. Use the Management API with a bearer token for admin tasks.
