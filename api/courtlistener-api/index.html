CourtListener API

Millions of U.S. court opinions, dockets, judges, and oral arguments.

What it does

CourtListener, run by the nonprofit Free Law Project, is the largest free database of U.S. court opinions, federal dockets (including mirrored PACER filings via RECAP), judges, oral-argument audio, and legal citations. The REST API v4 lets you search opinions by text, filter dockets by court and date, and pull judge bios with a token. Free accounts get a modest but usable daily quota.

What you can do with it

  • Search federal court opinions mentioning a company or legal topic
  • Watch a federal docket for new filings in a case you follow
  • Research a judge's background and prior rulings

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for CourtListener API ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Create a free account on CourtListener and verify your email.
  2. Go to your profile's API page and copy your token.
  3. Add 'Authorization: Token YOUR_TOKEN' as a header on API requests.
  4. Start with the search endpoint, using type=o for opinions or type=r for dockets.
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.
