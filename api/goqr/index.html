goQR

Creates QR codes from any text or link. No signup, just a URL.

What it does

goQR (api.qrserver.com) generates QR code images from whatever you give it: a website link, Wi-Fi login, contact card, or plain text. You set the size, colors, and format (PNG, SVG, etc.) right in the URL, and it returns the image directly. You can even embed the URL straight into a page. It can also read QR codes from uploaded images. No key and no hard request limit.

What you can do with it

  • Create QR codes for business cards, menus, or flyers that link to your website
  • Generate a Wi-Fi sharing QR code for your home or office
  • Add scannable product or event links to packaging and signage

  1. Read the docs page to see all options (size, colors, formats, error correction)
  2. Paste the example URL in a browser, replacing data=Example with your text or link
  3. Add &format=svg for a crisp vector version for printing
  4. Use the URL directly as an image on your site, or download and print it
