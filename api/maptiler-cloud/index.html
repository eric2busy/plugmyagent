MapTiler Cloud

Beautiful map tiles, geocoding, and elevation. 100k free requests a month.

What it does

MapTiler hosts gorgeous customizable maps built on open data, plus geocoding, IP location, and terrain services. The free plan needs no billing info and pauses (never bills) when you hit the limit, so it is safe to experiment. Free maps require the MapTiler logo and are for non-commercial use.

What you can do with it

  • Add a styled interactive map to a personal website
  • Geocode addresses for a small business directory
  • Show 3D terrain on a trip-planning page

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for MapTiler Cloud ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. 1. Create a free MapTiler Cloud account and copy your API key.
  2. 2. Drop the key into any map URL or SDK as ?key=YOUR_KEY.
  3. 3. Pick a style like streets, outdoor, or satellite and paste the snippet into your page.
  4. 4. Keep the required MapTiler logo and attribution visible on your map.
