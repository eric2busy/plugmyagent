Stytch

Passwordless-first auth free for 10,000 active users.

What it does

Stytch is an authentication API built around passwordless login: email magic links, one-time passcodes, OAuth, and WebAuthn passkeys. The free plan covers 10,000 B2C or B2B active users, unlimited B2B organizations, five SSO and SCIM connections, 10,000 device fingerprints, and 1,000 machine tokens. Its REST API uses your project ID and secret with HTTP Basic auth, and official SDKs cover every major platform. It is ideal if you want modern login without building it yourself.

What you can do with it

  • Add magic-link or passcode login without passwords.
  • Ship passkey login for web and mobile apps.
  • Manage B2B customers with SSO and directory sync.

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Stytch ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Create a free Stytch account and get your project ID and secret.
  2. Choose the login methods you want, such as magic links or passkeys.
  3. Install the Stytch SDK for your platform.
  4. Send a login request to start an authentication flow.
  5. Verify the session token on your backend.
