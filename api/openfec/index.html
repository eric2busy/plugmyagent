OpenFEC

Who gave money to whom in federal elections, from the Federal Election Commission.

What it does

OpenFEC is the Federal Election Commission's own API for campaign finance data: candidate filings, committee spending, and individual contributions to federal campaigns, all the way down to the donor level. It's the easiest legal way to see the money behind an election without downloading giant files. Free key, 1,000 calls an hour, and results come paginated in plain JSON.

What you can do with it

  • See who donated to a candidate or PAC before you vote
  • Visualize top spenders in a local House race for a blog post
  • Track how much campaigns spend on ads versus staff

1

Get free access

Sign up for OpenFEC ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Visit the developers page and register for a free API key.
  2. Add '?api_key=YOUR_KEY' to any endpoint, like /v1/candidates/.
  3. Filter by cycle, state, or office using the documented query parameters.
  4. Page through results with the 'page' parameter to see all records.
