What it does

Telegram's Bot API lets any app send messages, photos, files, and buttons to people on Telegram for free. You create a free bot through Telegram itself and get a secret token that acts as its password. Then sending a message is as simple as a link you can paste into a browser. It's why so many price trackers, server alerts, and small businesses run on Telegram.

What you can do with it

  • Send yourself instant alerts (website downtime, a stock alert, a completed backup) on your phone for free
  • Build a bot that texts order updates to customers on Telegram instead of paying for SMS
  • Create interactive buttons and menus for a booking or support bot

Set it up

  1. Install Telegram on your phone if you don't have it
  2. Open a chat with @BotFather and tap Start, then tap /newbot and give your bot a name
  3. Copy the token BotFather gives you. That's your API key
  4. Send a message to your new bot in the Telegram app
  5. Paste this in your browser (with your token and chat id): https://api.telegram.org/bot<TOKEN>/sendMessage?chat_id=<CHAT_ID>&text=It works

Example request

https://api.telegram.org/bot<TOKEN>/sendMessage?chat_id=<CHAT_ID>&text=Hello
