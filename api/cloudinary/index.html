Cloudinary

Free image and video hosting with on-the-fly transforms

What it does

Cloudinary hosts your images and videos and can resize, crop, and optimize them just by changing the URL. No code needed. The free plan gives you 25 credits a month with no credit card (1 credit = 1,000 transformations, 1 GB storage, or 1 GB of bandwidth). It's the easy way to serve fast, perfect images on any site.

What you can do with it

  • Hosting and resizing website images
  • User avatar uploads
  • Optimizing images for fast pages

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Cloudinary ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. 1. Sign up free at cloudinary.com.
  2. 2. Copy your cloud name, API key, and API secret from the dashboard.
  3. 3. Upload via the dashboard Media Library or the API.
  4. 4. Add transformations to the URL (w_300 for width, f_auto for format). Done.
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.

Set up Cloudinary for me so you can use it. HOW TO CALL IT https://res.cloudinary.com/YOUR_NAME/image/upload/w_300/sample.jpg AUTH: free API key. Mine: PASTE_KEY_HERE. Put it where the example above shows (usually an Authorization header or a key in the URL). FREE LIMIT: Free: 25 credits/month, no card required; all usage draws from one shared credit pool. TEST: once it's set up, ask it to fetch one small thing, like a repo or a fresh UUID. If you can't make web requests yourself, give me the exact curl command with my key filled in so I can run it. Docs if you get stuck: https://cloudinary.com/documentation

Keep API keys private. Only share yours with tools and people you trust.
