Discord Webhooks

Post messages automatically into a Discord channel. The easiest free notification pipe for any project.

What it does

Discord webhooks give you a special URL for one of your Discord channels. Anything sent to that URL shows up as a message in the channel. No coding required: tons of tools (GitHub, Stripe, Zapier) can post to a webhook directly, and even a spreadsheet script can do it. You can make messages pretty with formatting, pictures, and embeds.

What you can do with it

  • Get instant Discord pings when your website goes down or a sale comes in
  • Have GitHub automatically announce code updates to your team channel
  • Build a free 'alerts channel' for your small business team or community

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Discord Webhooks ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Open Discord and go to the server and channel where you want messages to land
  2. Click the gear next to the channel, then Integrations, then Create Webhook
  3. Give the webhook a name and copy its Webhook URL
  4. Paste that URL into whatever tool or script should send the messages
  5. Send a test message to see it appear in the channel
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.

Mine: PASTE_KEY_HERE. No separate key. Your webhook URL (Discord channel settings → Integrations → Webhooks) is the secret. Swap your full URL in for the example. FREE LIMIT: Free; about 30 requests per minute per webhook TEST: once it's set up, have it send you the message “plugmyagent test”. Keep API keys private. Only share yours with tools and people you trust.

Example request

POST https://discord.com/api/webhooks/{webhook.id}/{webhook.token} with {"content": "New order received!"}
