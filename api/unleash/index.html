Unleash

Dev Utilities No key

About

Unleash is the most-starred open-source feature-flag platform on GitHub, licensed under Apache 2.0 and free to self-host with no limits. It supports gradual rollouts, A/B testing, and kill switches through 15 official SDKs plus many community ones. You run the server with Docker alongside a Postgres database, and clients fetch flag definitions through a simple API. A managed cloud version exists for teams that prefer not to host it.

Setup

  1. Start Unleash and Postgres with Docker Compose.
  2. Log in to the admin UI with the default credentials and change them.
  3. Create a feature flag and define activation strategies.
  4. Generate a client API token for your application.
  5. Fetch flag states from the client API with the token.

Example
curl http://localhost:4242/api/client/features -H "Authorization: CLIENT_API_TOKEN"

Use cases

  • Decouple deploys from releases with flags you control at runtime.
  • Run canary releases to a slice of traffic before full rollout.
  • Give product teams a dashboard to manage flags without code changes.
