What it does

Novu is open-source notification infrastructure: one API to orchestrate email, SMS, push, in-app, and chat messages with templates, digest batching, and delivery tracking. You define workflows in code or the dashboard and trigger them with a single call, plugging in providers like SendGrid or Twilio. The free cloud tier covers 10,000 events a month, and you can self-host the whole thing.

What you can do with it

  • Send order updates across email and SMS from one trigger
  • Batch chatty notifications into a daily digest
  • Build a notification center inside your app

Set it up

  1. Create a free Novu account
  2. Create a workflow and add the channels you need
  3. Connect your delivery providers (email, SMS, push)
  4. Trigger the workflow from your app with your API key
  5. Watch delivery status in the activity feed

Example request

POST https://api.novu.co/v1/events/trigger with header Authorization: ApiKey <key>, plus name, to, and payload
