Smithsonian Open Access

Millions of museum artifacts, specimens, and images, free to reuse.

Open in PlugMyAgentOfficial docsGet free access

What it does

The Smithsonian's Open Access API gives you programmatic access to millions of museum artifacts, natural-history specimens, historic images, and even 3D models. Much of the content is free of copyright restrictions and cleared for reuse. You sign up with a free api.data.gov key, which takes seconds and needs no credit card.

What you can do with it

  • Build a natural-history explorer showing real specimen photos and 3D models
  • Pull historic images for a classroom or documentary project
  • Create a museum-collection search app by keyword, date, or department

Set it up

  1. Get a free key at api.data.gov/signup by entering your email (no credit card).
  2. Paste the example URL with your key to search the collections instantly.
  3. Change the q parameter to any keyword like 'dinosaur' or 'apollo'.
  4. Use the object endpoints in the docs to fetch full details, images, and 3D files.

Example request

https://api.si.edu/openaccess/api/v1.0/search?q=apollo&api_key=YOUR_KEY
