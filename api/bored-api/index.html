Bored API

Gives you a random real-world activity suggestion whenever you're bored.

What it does

The original Bored API at boredapi.com went offline, but a compatible version is now hosted by App Brewery at bored-api.appbrewery.com and it works the same way. Send it a request and it returns a random activity idea (like "Learn to play a song on the guitar") along with details like difficulty, cost, and how many people it takes. It's a simple way to get unstuck when you can't think of anything to do.

What you can do with it

  • Add a "give me an idea" button to a family or group chat that suggests things to do on weekends
  • Build a simple activity-picker app for date nights or kids' summer days
  • Use it as a first API to learn from when practicing how websites talk to each other

Follow the quick-start steps

Use the provider's instructions below. There's no secret key to manage.

  1. Open the docs page to see the available endpoints like /random and /activity
  2. Paste the example URL into a browser to see a sample activity returned as text
  3. To filter ideas, add options like ?type=recreational or ?participants=2 to the URL
  4. Use the URL in any app or website to fetch a fresh idea on demand
