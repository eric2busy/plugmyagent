Lemon Squeezy

Test the full payments API free in Test Mode before going live.

Open in PlugMyAgentOfficial docs

What it does

Lemon Squeezy is a merchant-of-record platform for selling digital products and subscriptions, handling taxes, VAT, and payouts for you. Its Test Mode is completely free and lets you build and test full integrations with test API keys that only touch test data. The REST API covers stores, products, checkouts, orders, subscriptions, and webhooks. When you are ready for real money, you switch to live keys after store approval.

What you can do with it

  • Build a complete checkout flow for digital products without touching real money.
  • Test subscription creation, renewals, and cancellations safely.
  • Prototype a SaaS billing integration before launch.

Set it up

  1. Create a Lemon Squeezy account and stay in Test Mode.
  2. Generate a test API key from your store settings.
  3. Create test products and a test checkout.
  4. Register a webhook endpoint to receive test events.
  5. Switch to live keys only after your store is approved.

Example request

curl -X POST https://api.lemonsqueezy.com/v1/webhooks -H "Accept: application/vnd.api+json" -H "Content-Type: application/vnd.api+json" -H "Authorization: Bearer {api_key}" -d '{"data": {"type": "webhooks", "attributes": {"url": "https://mysite.com/webhooks/", "events": ["order_created"], "secret": "SIGNING_SECRET"}, "relationships": {"store": {"data": {"type": "stores", "id": "1"}}}}}
