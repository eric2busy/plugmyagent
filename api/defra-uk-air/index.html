DEFRA UK-AIR

Britain's official air-pollution monitoring network.

What it does

The UK government's air-quality data service using the OGC Sensor Observation Service standard: live and historic measurements from the national monitoring network. No key needed, but be aware it's a technical XML standard. Friendlier than it sounds, yet aimed at developers.

What you can do with it

  • Build a UK city pollution dashboard
  • Research pollution near a specific station
  • Archive historic UK air-quality data
