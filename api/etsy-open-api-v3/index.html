Etsy Open API v3

Run your Etsy shop from code

What it does

Etsy's official API lets you manage the real work of selling: listings, inventory, orders, receipts, reviews, and shipping. Public shop and listing data is easy to read with just an API key; managing your own shop needs OAuth. It is built for sellers and the developers who serve them.

What you can do with it

  • Sync Etsy inventory with your own website or warehouse
  • Automate order processing and shipping labels
  • Build analytics on your shop's sales and reviews

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Etsy Open API v3 ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Create an app in the Etsy developer portal to get a keystring.
  2. Send it as the x-api-key header on every request.
  3. Complete the OAuth flow for access to your own shop's private data.
  4. Respect the x-limit-per-day and x-limit-per-second headers on responses.
3
