Bluesky (AT Protocol)

Publish posts and read the firehose on Bluesky with a free account and an app password.

Open in PlugMyAgentOfficial docsGet free access

What it does

Bluesky runs on the open AT Protocol, and its HTTP API is free for anyone with an account. You create an app password in settings, sign in, and then you can create posts with text, images, links, and replies, read feeds and profiles, and follow accounts. There is no developer application or key approval; the account itself is the credential. Great for bots, cross-posters, and social listening prototypes.

What you can do with it

  • Run a Bluesky bot that posts daily tips or quotes
  • Mirror your newsletter or RSS feed to Bluesky automatically
  • Prototype a social-listening tool on the public firehose

Set it up

  1. Create a free Bluesky account
  2. In Settings, create an app password for your tool
  3. Authenticate with your handle and app password to get a session token
  4. Create posts with the com.atproto.repo.createRecord endpoint
  5. Store the session and refresh it when it expires

Example request

POST https://bsky.social/xrpc/com.atproto.repo.createRecord with collection app.bsky.feed.post and a record containing your text
