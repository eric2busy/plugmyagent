Mastodon API

Post, schedule, and read engagement data on any Mastodon server through its open API.

What it does

Mastodon is a free, decentralized social network, and every server ships the same well-documented API. Register an app (or just get a token), and you can publish and schedule posts, upload media, read timelines and notifications, search, follow accounts, and manage lists. There is no developer portal or approval queue; your account on any server is all you need. It is ideal for indie cross-posters and fediverse analytics experiments.

What you can do with it

  • Auto-post blog updates to your Mastodon account
  • Build a cross-poster that sends one message to Mastodon, Bluesky, and Threads
  • Track mentions of your brand across the fediverse

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Mastodon API ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Pick a Mastodon server and create a free account there
  2. Go to Settings, then Development, and create a new application
  3. Copy the access token shown for your app
  4. Send posts with the token in the Authorization header
  5. Schedule posts with the scheduled_at parameter or poll for notifications
3
