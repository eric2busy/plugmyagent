Toggl Track

Simple time tracking API on a free plan

What it does

Toggl Track is a popular time tracking tool with a free-forever plan and a public API for time entries, projects, and clients. The API uses token-based basic authentication and also includes reporting and webhook APIs. It is well suited to freelancers and small teams.

What you can do with it

  • Start timers from a Slack command or shortcut
  • Generate client-ready time reports automatically
  • Sync tracked time with invoicing tools

Set it up

  1. Sign up for a free Toggl Track account
  2. Open your profile page and reveal your API token
  3. Authenticate with the token as the basic-auth username and api_token as the password
  4. Find your workspace ID with GET /api/v9/me
  5. Start and stop timers with the time entries endpoints
  6. Use the Reports API for aggregated analytics

Example request

GET https://api.track.toggl.com/api/v9/me/time_entries with basic auth API_TOKEN:api_token
