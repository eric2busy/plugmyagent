SwitchBot Open API v1.1

Control SwitchBot devices: bots, plugs, curtains, and locks.

What it does

SwitchBot's official Open API lets you control their smart buttons, plugs, curtains, locks, and sensors. You generate a token and secret directly in the SwitchBot phone app. No developer application or fee. Commands go through SwitchBot's cloud, so your devices need to stay online.

What you can do with it

  • Press buttons and flip switches remotely
  • Schedule curtains and plugs with your own automations
  • Include SwitchBot devices in multi-brand smart home routines

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for SwitchBot Open API v1.1 ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Install the SwitchBot app and add your devices.
  2. Open the app's developer options to generate a token and secret.
  3. Note both values. Requests must be signed with the secret.
  4. List your devices through the /v1.1/devices endpoint.
  5. Send commands like turnOn, press, or setPosition to control them.
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.

Put it where the example above shows (usually an Authorization header or a key in the URL).
