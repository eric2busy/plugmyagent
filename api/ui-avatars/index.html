UI Avatars

Makes clean initials-based avatars for any name, instantly.

Open in PlugMyAgentOfficial docs

What it does

UI Avatars generates simple, professional profile pictures showing a person's initials on a colored background. You control the name, colors, size, shape (square or rounded), and format through the URL. No account, no key, no tracking. It's the go-to default avatar for dashboards, admin panels, and apps where users haven't uploaded a photo.

What you can do with it

  • Auto-generate default profile pictures for new accounts in an app
  • Show consistent team member icons in project tools and dashboards
  • Add professional-looking avatars to email signatures or contact lists

Set it up

  1. Paste the example URL into a browser to see an avatar for the name
  2. Customize with options like &background=0D8ABC&color=fff&size=128&rounded=true
  3. Use &background=random for a different color per person
  4. Drop the URL into your app as the default avatar image

Example request

https://ui-avatars.com/api/?name=Elon+Musk
