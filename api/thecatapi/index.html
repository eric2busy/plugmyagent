About

TheCatAPI is exactly what it sounds like: tens of thousands of cat images with breed information and cat facts, all through a simple REST API. The free tier includes 10,000 requests a month with a free key. It also supports voting, favorites, and image uploads for interactive apps.

Details

Free to start. You may need a free key, but no credit card.

Auth: Free key (no card)

Rate limit: 10,000 requests/month on the free tier

Verified: 2026-09-13

Best for: cats images breeds

Read the docs Back to catalog

Setup

  1. Sign up for a free API key on the official site.
  2. Pass the key in the x-api-key header with each request.
  3. Fetch random images with /v1/images/search, optionally filtered by breed.
  4. Pull breed details and cat facts from their dedicated endpoints.
  5. Use the voting and favorites endpoints to make interactive apps.

GET https://api.thecatapi.com/v1/images/search

Use cases

  • Add random cat images to an app or website
  • Build a breed-explorer for cat lovers
  • Create a cat-picture-of-the-day bot
