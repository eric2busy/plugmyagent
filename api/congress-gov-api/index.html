What it does

This is the official API from the Library of Congress for everything Congress does: bill text and status, roll-call votes, member profiles, committee hearings, nominations, treaties, and the Congressional Record. It replaced older third-party feeds with the government's own data, so it's authoritative and current. A free key gets you 5,000 requests per hour.

What you can do with it

  • Get an alert or auto-updated page whenever a bill you care about changes status
  • Look up how your representative voted on recent bills for a voter guide
  • Build a tracker for committee hearings on topics like housing or tech

Set it up

  1. Go to the sign-up page and request a free API key with your email.
  2. Copy your key into the api_key parameter of any request.
  3. Try the example bill endpoint in your browser to see the data format.
  4. For step-by-step recipes, read the Quick Start guide linked in the docs.

Example request

https://api.congress.gov/v3/bill?api_key=YOUR_API_KEY
