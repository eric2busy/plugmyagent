Advice Slip

Random pieces of life advice, from wise to wonderfully weird.

Open in PlugMyAgentOfficial docs

What it does

Advice Slip serves up short random advice slips - some genuinely useful, some hilariously odd. Every piece of advice has its own ID, so you can fetch a specific one again later or search advice by keyword. Free with no sign-up.

What you can do with it

  • A 'words of wisdom' button in an app
  • Daily advice posts on social media
  • Fun placeholder wisdom in prototypes

Set it up

  1. Open https://api.adviceslip.com/advice in your browser for random advice.
  2. Note the 'id' number in the response.
  3. Fetch that exact slip again with https://api.adviceslip.com/advice/117.
  4. Search advice with https://api.adviceslip.com/advice/search/life.
  5. No key or account required.

Example request

https://api.adviceslip.com/advice
