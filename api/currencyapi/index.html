CurrencyAPI

Free currency exchange rates with a simple key

What it does

CurrencyAPI provides daily-updated foreign exchange rates for 180+ currencies through a simple REST API with a free key. You can use it to build a travel budget converter, to show product prices in a shopper's local currency, or to log daily exchange-rate history for a finance report. The free tier includes a few hundred requests a month, which is plenty for a personal converter or a small site.

What you can do with it

  • Travel budget converter for an upcoming trip
  • Show prices in a shopper's local currency
  • Log daily exchange rates for a finance report

Set it up

  1. Sign up for a free account at currencyapi.com and confirm your email.
  2. Copy your API key from the dashboard.
  3. Open the docs at https://currencyapi.com/docs to see the endpoints.
  4. Try the example latest-rates URL in your browser with your key.
  5. Cache the daily rates in your app so your 300 monthly calls go far.

Example request

https://api.currencyapi.com/v3/latest?apikey=YOUR_KEY&base_currency=USD
