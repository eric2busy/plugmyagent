FRED API

Free key to the U.S. economy's official statistics

What it does

FRED, run by the Federal Reserve Bank of St. Louis, is the official home of U.S. economic time series like inflation, unemployment, interest rates, and GDP. You can use it to chart unemployment over decades, to pull the latest inflation numbers into a report, or to compare mortgage rates across years. A free registered key unlocks the full API with no published hard cap, which makes it a staple for research and content.

What you can do with it

  • Chart unemployment or inflation over decades
  • Pull the latest CPI numbers into a monthly report
  • Compare mortgage and Treasury rates across years

2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Go to the FRED API key page and register for a free account.
  2. Request an API key and copy it from your account page.
  3. Browse series on fred.stlouisfed.org to find IDs like UNRATE or CPIAUCSL.
  4. Try the example unemployment URL in your browser with your key.
  5. Read the series-observations docs to add date ranges and units to your calls.
