World Air Quality Index (WAQI)

Live air quality from thousands of monitoring stations worldwide.

Open in PlugMyAgentOfficial docs

What it does

The World Air Quality Index project pulls readings from government and community sensors into one simple API. You can check the AQI (air quality index) for a city, plus pollutants like PM2.5 and ozone. Free use is for non-commercial projects and asks for attribution back to the project.

What you can do with it

  • Check if today's AQI is bad enough to skip an outdoor workout
  • Compare air quality between Covina and Long Beach
  • Add an AQI badge to a weather page

Set it up

  1. 1. Request a free API token on the WAQI API page.
  2. 2. Look up your city with /feed/CITY_NAME/?token=YOUR_TOKEN.
  3. 3. The 'aqi' number tells you how clean the air is. Higher means worse.
  4. 4. Include the required attribution line ('Source: World Air Quality Index project') if you publish the data.

Example request

https://api.waqi.info/feed/shanghai/?token=demo
