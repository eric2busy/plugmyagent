Clerk

Drop-in login and user management free for 50,000 returning users.

Open in PlugMyAgentOfficial docsGet free access

What it does

Clerk provides ready-made sign-in, sign-up, and user-profile components plus a Backend API for user management. The Hobby plan is free and, since February 2026, includes 50,000 monthly retained users, which counts users who return at least a day after signing up. It handles sessions, organizations, and social logins out of the box with polished UI components. The Backend API uses a secret key bearer token for admin tasks like listing users.

What you can do with it

  • Add polished login and signup UI to a React or Next.js app in minutes.
  • Manage users, sessions, and organizations without a custom backend.
  • Gate features by user role or organization membership.

Set it up

  1. Create a free Clerk account and application.
  2. Copy your publishable and secret API keys.
  3. Install the Clerk SDK for your framework.
  4. Add the sign-in and user-profile components to your app.
  5. Use the Backend API with your secret key for admin operations.

Example request

curl https://api.clerk.com/v1/users -H "Authorization: Bearer sk_test_xxx"
