About

Zhipu's BigModel platform prices its GLM Flash family at free on the official pricing table: GLM-4.7-Flash with a 200K context window, plus GLM-4-Flash, GLM-Z1-Flash, vision Flash models, the CogView-3-Flash image model, and CogVideoX-Flash for video. This is standing free pricing, not a trial. Endpoints are OpenAI-compatible (and Claude Responses-compatible).

Setup

  1. Go to open.bigmodel.cn and create an account (no card).
  2. Create an API key in the console.
  3. Point your OpenAI-compatible client at the BigModel endpoint.
  4. Pick a Flash model for text, or CogView-3-Flash / CogVideoX-Flash for image and video.
