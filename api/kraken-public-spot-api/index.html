Kraken Public Spot API

No-key crypto prices, order books, and OHLC data

What it does

Kraken's public API serves ticker prices, order-book snapshots, recent trades, and OHLC candlestick data for its spot markets with no key required. You can use it to compare Kraken prices against another exchange, to pull hourly candles for a charting side project, or to monitor the bid-ask spread of a coin you hold. Public endpoints are rate-limited by a request counter, so gentle pacing keeps your calls flowing.

What you can do with it

  • Compare Kraken prices against another exchange
  • Pull hourly candles for a charting side project
  • Monitor bid-ask spreads on coins you hold

Follow the quick-start steps

Use the provider's instructions below. There's no secret key to manage.

  1. No account needed. Open the API docs at https://docs.kraken.com/api/.
  2. Try the example ticker URL in your browser to see the response format.
  3. Look up the asset-pair names in the docs (for example, XBTUSD for Bitcoin).
  4. Try the OHLC endpoint to get candlestick history for charts.
  5. Space your requests out so the rate counter never maxes out.
