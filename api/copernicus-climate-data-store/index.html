Copernicus Climate Data Store

The EU's climate archive, from 1940 to today.

What it does

The EU's Copernicus program makes its climate reanalysis and projection datasets (ERA5 and friends) downloadable through a Python client. Free account with a personal access token; you also accept each dataset's license once. Requests are queued, not instant. Plan accordingly.

What you can do with it

  • Download decades of temperature reanalysis data
  • Research long-term climate trends
  • Feed climate data into machine-learning models

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Copernicus Climate Data Store ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Create a free account at cds.climate.copernicus.eu
  2. Accept the license for the datasets you want
  3. Install cdsapi (pip install cdsapi) and paste your personal access token
