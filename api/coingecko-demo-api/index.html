CoinGecko Demo API

The classic free crypto price and market-data API

Open in PlugMyAgentOfficial docs

What it does

CoinGecko's Demo API provides free access to real-time prices, market caps, volumes, and basic historical data for thousands of cryptocurrencies. No credit card required. Free keys get 10,000 monthly credits; commercial or high-volume use needs a paid plan. CoinGecko is one of the largest independent crypto data aggregators.

What you can do with it

  • Crypto price dashboards and tickers
  • Portfolio valuation and allocation tracking
  • Alert bots for price movements

Set it up

  1. Create a free CoinGecko account (no credit card).
  2. Copy your free Demo API key from the API dashboard.
  3. Send it in the x-cg-demo-api-key header on every request.

Example request

GET https://api.coingecko.com/api/v3/simple/price?ids=bitcoin,ethereum&vs_currencies=usd  (header: x-cg-demo-api-key)
