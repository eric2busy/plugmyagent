AbuseIPDB

Community-reported IP abuse scores: is this IP a spammer, scanner, or bot?

What it does

AbuseIPDB is a crowd-sourced blocklist where sysadmins and security folks report IP addresses for brute-force logins, spam, port scans, and DDoS attacks. Each IP gets an 'abuse confidence score' from 0–100 based on how many independent users reported it and how recently. The free API gives you 1,000 checks a day. Plenty for a home server, a website firewall, or a fun reputation-checker app.

What you can do with it

  • Auto-block login attackers on your own server when their score is high
  • Show visitors an IP's abuse score on a security dashboard
  • Report an attacker back to the community to help everyone

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for AbuseIPDB ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Register a free account at abuseipdb.com and create an API key under Account → API.
  2. Send requests to https://api.abuseipdb.com/api/v2/check with your key in the 'Key' header.
  3. Read the abuseConfidenceScore, totalReports, and countryCode in the response.
  4. Cache results locally so you don't burn your daily quota on repeat checks.
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.

Mine: PASTE_KEY_HERE. Put it where the example above shows (usually an Authorization header or a key in the URL). FREE LIMIT: Free tier: 1,000 checks per day. TEST: once it's set up, ask it to check a domain or IP address you know. If you can't make web requests yourself, give me the exact curl command with my key filled in so I can run it.
