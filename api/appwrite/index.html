Appwrite

Open-source backend with database, auth, storage, and functions in one.

What it does

Appwrite is a self-hosted or cloud backend platform that gives you a database, user login, file storage, and serverless functions behind one simple API. The free cloud plan includes 750,000 function executions, 75,000 monthly active users, 2 GB of storage, and 5 GB of bandwidth per month, plus 500,000 database reads and 250,000 writes monthly. Projects pause after one week of inactivity, so it is best for active projects and prototypes.

What you can do with it

  • Store and query app data without running your own database server.
  • Add email, social, and anonymous user login to a project in minutes.
  • Run small backend tasks with serverless functions instead of a server.

1

Get free access

Sign up for Appwrite ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Create a free account at appwrite.io or self-host with Docker.
  2. Create a project and note your project ID.
  3. Generate an API key from the project settings.
  4. Create a database and a collection for your data.
  5. Send requests with the X-Appwrite-Project and X-Appwrite-Key headers.
