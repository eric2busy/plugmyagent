What it does

Etherscan's API lets you query the Ethereum blockchain and supported networks for wallet balances, transaction histories, token transfers, gas prices, and contract details. You can use it to build a wallet balance checker, to track token transfers into an address, or to look up the current gas price before sending a transaction. The free tier requires a key but is generous enough for personal explorers and bots.

What you can do with it

  • Wallet balance and transaction history checker
  • Track token transfers into a specific address
  • Look up live gas prices before transacting

Set it up

  1. Create a free Etherscan account and go to https://etherscan.io/myapikey.
  2. Generate an API key token and copy it.
  3. Open the API docs to find the module you need (account, transaction, contract, gas).
  4. Try the example balance URL in your browser with your key.
  5. Pace your calls at 3 per second or slower so nothing gets throttled.

Example request

https://api.etherscan.io/v2/api?chainid=1&module=account&action=balance&address=0xde0b295669a9fd93d5f28d9ec85e40f4cb697bae&tag=latest&apikey=YOUR_KEY
