About

Twilio Verify is a separate API just for one-time passcodes. Those 6-digit login codes. It handles the whole flow: sending the code by SMS, voice call, email, WhatsApp, or authenticator app, checking the code the user types in, blocking fraud, and retrying if the first attempt fails. Way simpler than building login-code logic yourself.

Setup

  1. Create a Twilio account and open the Verify console
  2. Create a Verify service and pick your channels (SMS, voice, email, WhatsApp)
  3. Send a verification code to a phone number with one API call
  4. Show your user a code-entry screen
  5. Check the code with a second API call to confirm it's valid
Sign up
Example
Start verification: POST https://verify.twilio.com/v2/Services/{sid}/Verifications with To and Channel='sms'

Use cases

  • Add two-factor login codes to your app's sign-in flow
  • Verify a customer's phone number at signup to block fake accounts
  • Send password-reset codes that arrive in seconds
