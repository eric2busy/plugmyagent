CometChat

Messaging & Chat Free key (no card)

About

CometChat gives you ready-made chat widgets with text, voice calls, and video calls baked in, so your app can get messaging in an afternoon. The free Build plan (no credit card) supports up to 100 users with all features turned on. Meant for development and testing rather than big production apps.

Details

Free to start. You may need a free key, but no credit card.

Auth: Free key (no card)

Rate limit: Free Build plan: up to 100 users, all features, no credit card; for development/testing

Verified: 2026-09-13

Best for: business developer

Read the docs Back to catalog

Setup

  1. Sign up for free at the CometChat dashboard
  2. Create an app and copy your App ID, region, and auth key
  3. Install the UI kit for your platform (web, iOS, Android, Flutter)
  4. Log users in and start a one-on-one or group chat
  5. Add voice/video calling with the calling extension
Sign up
Example
Send a text: POST https://{app-id}.api-{region}.cometchat.io/v3/messages with receiver, receiverType, and text

Use cases

  • Prototype a social app's messaging in days with prebuilt widgets
  • Add in-app voice and video calls to a collaboration tool
  • Test chat features with a small beta group before launch
