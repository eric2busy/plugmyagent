Deck of Cards

A full deck of cards in the cloud - shuffle, draw, and play.

What it does

The Deck of Cards API gives you virtual card decks you can shuffle, draw from, and pile up, with images for every card. It remembers your deck between requests via a deck ID, so you can build real card games like poker or blackjack. Free, no key.

What you can do with it

  • Building online card games (poker, blackjack, solitaire)
  • A 'draw a card' decision or fortune feature
  • Teaching game logic to new programmers

2

Follow the quick-start steps

Use the provider's instructions below. There's no secret key to manage.

  1. Read the docs at https://deckofcardsapi.com/.
  2. Create a shuffled deck: https://deckofcardsapi.com/api/deck/new/shuffle/?deck_count=1.
  3. Save the 'deck_id' from the response.
  4. Draw cards: https://deckofcardsapi.com/api/deck/YOUR_DECK_ID/draw/?count=5.
  5. Each card comes with an image URL - display them directly.
