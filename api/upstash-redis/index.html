Upstash Redis

Free serverless Redis for caching and queues

What it does

Upstash provides Redis. A super-fast in-memory database. As a serverless cloud service. The free tier gives you 256 MB of data and 500,000 commands per month with no credit card required. It's great for caching, session storage, and message queues, and it connects over a simple REST API or standard Redis protocol.

What you can do with it

  • Caching API responses
  • Session and rate-limit storage
  • Real-time leaderboards and counters

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Upstash Redis ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. 1. Sign up at upstash.com.
  2. 2. Create a Redis database from the console.
  3. 3. Copy the REST URL and read/write tokens from the database details.
  4. 4. Call the REST API with curl or use the token in your app's Redis client.
