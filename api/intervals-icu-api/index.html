Intervals.icu API

Deep training analytics for cyclists, runners, and triathletes.

What it does

Intervals.icu is a free training analytics platform that syncs with Strava, Garmin, and other services. Its API exposes activities, wellness data, training calendars, workout libraries, power curves, and gear. A personal API key is generated right in your own settings, so solo automation works with no app review process.

What you can do with it

  • Download your training history for custom analysis
  • Sync wellness and load data to a personal dashboard
  • Automate workout uploads and training-plan management

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Intervals.icu API ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Create a free Intervals.icu account and connect your Strava or Garmin.
  2. Open Settings, go to the Developer section, and generate a personal API key.
  3. Use HTTP basic auth with your API key as the username.
  4. Pull activities, wellness, and calendar data from the v1 endpoints.
  5. Cache results where possible to stay within the published limits.
