Flagsmith

Feature flags free for 50,000 requests a month, unlimited self-hosted.

Open in PlugMyAgentOfficial docs

What it does

Flagsmith is a feature-flag and remote-config service that lets you toggle features and roll out changes without redeploying code. The free cloud plan includes 50,000 requests per month, one team member, and unlimited feature flags, environments, identities, and segments. If you self-host the open-source version, there are no limits on users, flags, or environments at all. SDKs cover every major language and framework.

What you can do with it

  • Roll out a new feature to a small percentage of users first.
  • Turn off a broken feature instantly without a deploy.
  • Run A/B tests by serving different flag values to different users.

Set it up

  1. Sign up for free cloud or self-host with Docker.
  2. Create a project and an environment.
  3. Create a feature flag in the dashboard.
  4. Copy your environment API key.
  5. Evaluate flags in your app with the SDK or the REST API.

Example request

curl https://edge.api.flagsmith.com/api/v1/flags/ -H "X-Environment-Key: YOUR_ENV_KEY"
