GovInfo API

Official U.S. laws, bills, the Congressional Record, and Federal Register in one API.

What it does

GovInfo is the Government Publishing Office's official source for U.S. laws: the U.S. Code, the Code of Federal Regulations, congressional bills and reports, the daily Congressional Record, public laws, and more. This API lets you list what's new in each collection, grab document metadata as JSON, and download the actual PDFs or text. A free api.data.gov key works here with generous limits.

What you can do with it

  • Track when new bills are introduced in a collection you're watching
  • Download the official text of a public law for legal research
  • Build an archive that watches the Federal Register for new rules

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for GovInfo API ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Get a free api.data.gov key (the same key used for several other government APIs).
  2. List available collections with /collections?api_key=YOUR_KEY.
  3. Query a collection by date to find new documents, then fetch a package summary.
  4. Download content files via the granules or download links in the response.
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.
