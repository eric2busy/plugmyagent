Google Search Console API

Pull your site's Google search clicks, impressions, and rankings into any report.

Open in PlugMyAgentOfficial docsGet free access

What it does

This is Google's official API for Search Console data: the same clicks, impressions, click-through rates, and average positions you see in the Search Console dashboard, available as data you can query. It also covers sitemaps, site verification, and URL inspection. Access uses OAuth on sites you have verified in Search Console, and the API itself is free.

What you can do with it

  • Build a weekly SEO report showing top queries and pages
  • Alert yourself when clicks drop sharply for important keywords
  • Combine rankings data with sales data to find money keywords

Set it up

  1. Verify your website in Google Search Console
  2. Create a Google Cloud project and enable the Search Console API
  3. Set up OAuth credentials and authorize access to your Search Console data
  4. Query the searchAnalytics endpoint for your date range and filters
  5. Schedule the query to feed a dashboard or spreadsheet

Example request

POST https://www.googleapis.com/webmasters/v3/sites/{siteUrl}/searchAnalytics/query with startDate, endDate, and dimensions like query and page
