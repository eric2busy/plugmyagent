About

Hetzner's experimental inference API is one of the most generous free inference endpoints anywhere: OpenAI-compatible, serving Qwen3.6-35B with a 262k context window and vision support, with limits of 500M input and 5M output tokens per day. It is free while experimental with just a Hetzner account (no credit card), but there is no SLA and it is not for production. Perfect for prototyping agents and running free-tier coding agents at real scale.

Setup

  1. Create a Hetzner account and open the inference console.
  2. Issue a free API token (no credit card).
  3. Point any OpenAI-compatible client at inference.hetzner.com/api/v1.
  4. Set the model to Qwen/Qwen3.6-35B-A3B-FP8.
  5. Build and prototype; move to a paid provider before production.

Example
curl https://inference.hetzner.com/api/v1/chat/completions -H "Authorization: Bearer YOUR_TOKEN" -d '{"model":"Qwen/Qwen3.6-35B-A3B-FP8","messages":[{"role":"user","content":"Hello"}]}'
