Cloudflare DNS over HTTPS

Look up any domain's DNS records over encrypted HTTPS, no key needed.

What it does

DNS-over-HTTPS turns boring DNS lookups into simple web requests: you ask Cloudflare's 1.1.1.1 resolver 'what's the IP of example.com?' as an HTTPS URL and get JSON back. Because it runs over HTTPS, nobody on your network can snoop on or tamper with the lookups, and the JSON format is easy to use from any app or even a browser address bar. No key, no account, free forever.

What you can do with it

  • Check a domain's mail (MX) or text (TXT) records from a web app
  • Build a privacy-friendly DNS lookup tool that works in any browser
  • Verify a website's DNS answers match what you expect during troubleshooting
