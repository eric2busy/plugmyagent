Firebase Authentication

Google's login service free for 50,000 monthly users.

What it does

Firebase Authentication is Google's hosted login service for email-password, phone, and social sign-in, usable through client SDKs and a REST API. The free Spark plan covers 50,000 monthly active users for standard authentication and 50 monthly users for SAML and OIDC enterprise providers, with the first 10 SMS verifications per day free. Phone authentication beyond that requires the pay-as-you-go Blaze plan. It is separate from Firebase's Firestore database and pairs well with any Google Cloud backend.

What you can do with it

  • Add email and social login to a mobile or web app quickly.
  • Verify users by SMS for onboarding flows.
  • Use Google-managed sessions with a Firebase or GCP backend.

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Firebase Authentication ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Create a free Firebase project in the console.
  2. Enable Authentication and turn on the sign-in methods you want.
  3. Register your app and copy the API key and project config.
  4. Install the Firebase Auth SDK for your platform.
  5. Sign users in with the SDK or call the Identity Platform REST endpoints.
3

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.
