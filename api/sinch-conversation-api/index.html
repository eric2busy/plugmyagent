Sinch Conversation API

One API for SMS, WhatsApp, RCS, and MMS. No-card trial credit to start.

What it does

Sinch's Conversation API lets you message customers on whatever channel they prefer. SMS, WhatsApp, RCS, MMS, and more. Through a single API instead of wiring up five different ones. Trial signups include credit with no credit card required. Note: Sinch retired its older standalone SMS API in April 2026. Conversation API is the current product.

What you can do with it

  • Message customers on their favorite app without integrating each one separately
  • Send rich RCS messages with images and buttons on Android
  • Run a support chatbot across WhatsApp, SMS, and Messenger

Set it up

1

Get free access

Open the provider's signup page and make a free account.

Sign up for Sinch Conversation API ↗
2

Copy your API key

After signing up, look in the dashboard or settings for your API key, then copy it. The provider-specific steps are below.

  1. Sign up and create a Sinch project with no card
  2. Create an app and access key in the dashboard
  3. Send your first test message with the quickstart code
  4. Connect WhatsApp or RCS channels to the same app
  5. Point incoming-message webhooks at your app to hold two-way chats
3

Tell your agent

Copy the message, paste it into ChatGPT, Claude, Grok, or a similar agent. No code needed. Replace PASTE_KEY_HERE with your key first. Your agent will either set it up directly or hand you the exact command to run.
