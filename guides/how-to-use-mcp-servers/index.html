How to use MCP servers

MCP is one standard way for your agent to reach files, apps, and services. Three moves and your agent has a new tool.

01 Run the install command

Most servers install with one command. No accounts, no dashboards, no waiting. Copy the install command from the server's listing on the MCP directory and run it in your terminal.

02 Paste the config

Copy the config block into your MCP client (Claude Desktop, Cursor, or your agent setup). Swap in your own paths or keys where marked. Each server listing has a Client config section with the exact block to paste.

03 Restart and ask

Restart the client and ask your agent to use the new tool. If it can see it, it is working. Try asking it to list its available tools, or give it a small task that uses the new server.

Stuck?

Check the Source link on the server's listing for the latest official docs. Install commands change; the source repo always has the current version.
