Pick your agent:
nine agents, one choice.

Every guide on this site works with any agent. But you have to pick one to start. Here are the nine major personal agents, what each one is actually good at, what it costs to start, and how to set it up. One of them is the right first agent for you.

Compare the nine Setup walkthroughs
The short version

Want it on your phone in 10 minutes? Start with Muse. Want it on your own machine, fully yours? Start with OpenClaw. Already live in ChatGPT, Claude, or Grok? Stay there, they all connect tools too. The rest of this guide is the detail behind that answer.

01What you are actually choosing

All nine agents do the same core job: you hand them an outcome, they do the work. The differences are where they live, what they cost, and how you talk to them.

  1. Where it lives. Phone app, web, text message, or your own machine. Pick the one you will actually open every day.
  2. What it costs to start. Eight of the nine start free. Poke is the exception: you negotiate a monthly price.
  3. How it connects tools. Every one of these connects external tools (APIs, MCP servers, built-in integrations). The path differs, the outcome is the same: your agent can fetch live data instead of guessing.

02The nine agents

Read the one that sounds like you. Each entry links to its setup walkthrough.

Muse: the 10-minute phone agent

Meta's personal AI agent with its own virtual computer. It acts, schedules, runs multi-step tasks, and works over web, iOS and Android apps, and WhatsApp. US and Canada, 18+. Free to start with a weekly token allowance; a paid Power plan exists for heavier use.

Best for: the fastest start. If you want an agent on your phone in 10 minutes with no terminal, this is the one.

Tools: Settings → Connectors → Add custom connector. Supports remote MCP servers plus native connectors for email, calendar, shopping, and smart home.

OpenClaw: the self-hosted agent

Free, open-source, runs on your own machine or server. Chat via browser dashboard, WhatsApp, Telegram, or Discord. You pick the model that powers it: Anthropic, OpenAI, OpenRouter, or a local model via Ollama (free).

Best for: full ownership. If you want the agent on your hardware, with your data, under your control, this is the one.

Tools: MCP-native. openclaw mcp set adds a server; config lives in ~/.openclaw/openclaw.json.

Set up OpenClaw →

ChatGPT: the one you already know

OpenAI's assistant: chat, Codex coding agent, tasks, voice, image generation. Free tier; Plus and Pro paid tiers. If you already use ChatGPT every day, you already have an agent. Connect tools and it stops being a chatbot.

Best for: staying where you already are. The largest user base, the most integrations, the most familiar interface.

Tools: prebuilt Apps (Gmail, Drive, and more) plus MCP via Developer Mode on paid plans. The free plan does not get custom MCP.

Set up ChatGPT with tools →

Claude: the writer and coder

Anthropic's assistant: chat plus Claude Code. Strong at writing, coding, and analysis. Free tier; Pro and Max paid tiers. Anthropic created MCP, so Claude's tool support is the deepest of the nine.

Best for: writing and coding work, and anyone who wants the most mature tool ecosystem.

Tools: Settings → Connectors for built-in integrations (Gmail, Calendar, Drive, Slack, Notion), plus custom MCP servers. In Claude Code: claude mcp add.

Set up Claude with tools →

Grok: the X-native agent

xAI's assistant at grok.com, in the X app, and in its own app. Free tier; paid SuperGrok tiers. Grok Bot is the separate always-on cloud-computer teammate (desktop app). If you live on X, Grok is already in your pocket.

Best for: X users, and anyone who wants a teammate-style agent with its own desktop app.

Tools: grok.com Connectors → New Connector → Custom (remote MCP). Grok Bot adds plugins and skills.

Set up Grok with tools →

Manus: the autonomous operator

General-purpose autonomous agent. Manus 2.0 has a persistent Cloud Computer, Automations, and a Studio desktop app. Cue is its standalone personal-agent app: each agent gets its own email, phone number, wallet, and computer. Cue is in early access via invite.

Best for: hands-off automation. Manus is built to run long tasks on its own computer and report back.

Tools: custom MCP servers (Settings → Integrations), Skills, OAuth Connectors, Zapier, and a Manus API.

Set up Manus →

Genspark: the all-in-one workspace

All-in-one AI workspace: chat across many models, research, slides, sheets, images, video, browser, and a Super Agent. Free tier with credits; Plus plan for heavier use.

Best for: one workspace instead of five apps. If you want documents, research, and agent work in one place, this is the one.

Tools: MCP integrations (hundreds of tools) via the Tools section and MCP Store: Gmail, Calendar, Notion, Slack, Outlook, X, Reddit, and more.

Set up Genspark →

Poke: the agent you text

The AI agent you text, the first approved to run natively inside iMessage, plus SMS and WhatsApp. Proactive nudges, integrations, and a negotiated-price model: you haggle once on the monthly price (reported roughly $2 to $29 a month). No published free tier.

Best for: people who live in messages. If you want an agent that feels like texting a very capable friend, this is the one.

Tools: integrations (Gmail, Calendar, Notion, Linear, Oura, and more), Recipes, and MCP support.

Set up Poke →

Instinct: the invite-only agent

Invite-only personal agent you text or call (iMessage, WhatsApp, SMS). It has its own phone number, email address, and cloud computer, and acts across your accounts: booking, buying, following up, calling on your behalf. Free during beta; no price announced. Join the waitlist or get an invite from an existing member (each member gets 5 invites).

Best for: early adopters who want an agent that acts across their accounts with the least setup.

Tools: connects to your email, calendar, and messaging apps natively. Agents coordinate with each other through a trusted network (Instinct-to-Instinct only).

03How to choose in 60 seconds

Answer these three questions in order. The first one that gives you a clear answer is your pick.

  1. Where do you want it? Phone → Muse. Your own machine → OpenClaw. Text messages → Poke or Instinct. Where you already are → ChatGPT, Claude, or Grok.
  2. What will it do most? Writing and coding → Claude. Hands-off automation → Manus. Everything in one workspace → Genspark. General daily work → Muse, ChatGPT, or Grok.
  3. Still stuck? Start with Muse. It is the fastest setup on this page, it is free, and everything you learn transfers: the delegation recipe, the approval habit, and the three moves for connecting tools all work the same on every agent.

04After you pick

Two steps and you are working:

  1. Run the setup walkthrough for the agent you picked. Each one ends with a working agent, not a theory.
  2. Connect your first API with guide 004. Ten minutes, no signup on the fast path, and it works with whichever agent you chose.
