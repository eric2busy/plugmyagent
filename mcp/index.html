Pillar 02 // One standard plug

MCP Server Directory

MCP is one standard way for your agent to reach files, apps, and services. Pick a server below, run its install command, paste the config into your agent client, and it can use that tool right away.

Step 01

Run the install command

Most servers install with one command. No accounts, no dashboards, no waiting.

Step 02

Paste the config

Copy the config block into your MCP client (Claude Desktop, Cursor, or your agent setup). Swap in your own paths or keys where marked.

Step 03

Restart and ask

Restart the client and ask your agent to use the new tool. If it can see it, it is working.

    34 servers, verified against official repos on September 19, 2026. Install commands and configs come from the official documentation. If a command fails, check the source link for the latest version.

    Every server here is free to run. Anything that needs a key only needs a free one.
