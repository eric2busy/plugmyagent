Config for your agent

Pick your agent and copy the block into its MCP config file. The setup guide shows where that file lives for each agent.

{
  "mcpServers": {
    "exa": {
      "type": "http",
      "url": "https://mcp.exa.ai/mcp"
    }
  }
}
{
  "mcpServers": {
    "exa": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://mcp.exa.ai/mcp"
      ]
    }
  }
}
[mcp_servers.exa]
url = "https://mcp.exa.ai/mcp"

How to use it

  1. Copy the config block above for your agent.
  2. Paste it into your agent's MCP config file.
  3. Restart your agent so it picks up the new server.
  4. Ask your agent to use it.

Before you install

Is it free?
Yes. Exa is open source under the UNVERIFIED license and free to run. It needs an API key from the provider; a free account or free tier covers normal use.
What do I need first?
an account with the service, since this server runs remotely.

If it does not show up

  • Fully quit and relaunch your agent app after editing the config. Closing the window is not always enough for desktop apps.
  • Check the JSON is valid: one trailing comma breaks the whole file. Our MCP Config Validator checks it in your browser.
