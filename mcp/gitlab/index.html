How to use it

  1. Copy the config block above for your agent.
  2. Paste it into your agent's MCP config file.
  3. Restart your agent so it picks up the new server.
  4. Ask your agent to use it.

Before you install

Is it free?
Yes. GitLab is open source under the MIT license and free to run. It needs an API key from the provider; a free account or free tier covers normal use.
What do I need first?
Node.js 18 or newer (which provides npx); values for GITLAB_PERSONAL_ACCESS_TOKEN (they go in the env block of the config).

If it does not show up

  • Fully quit and relaunch your agent app after editing the config. Closing the window is not always enough for desktop apps.
  • Check the JSON is valid: one trailing comma breaks the whole file. Our MCP Config Validator checks it in your browser.
  • If the log says "npx: command not found", the runtime above is missing or the app cannot see your PATH. Install it, then relaunch the app.
  • If the server starts but every call fails, a credential is usually wrong or expired: GITLAB_PERSONAL_ACCESS_TOKEN.
