How we check

plugmyagent is a hand-maintained catalog. This page says exactly how a tool gets listed, what we publish about it, and how the MCP scorecard is graded, so you can hold us to it.

How a listing gets in

A person picks every listing. Three tests decide it: the free tier has to be real (usable without a card, not a timed trial wearing a free costume), the documentation has to be live, and the install or signup path has to work the way the page describes it. If a tool fails a test later, the listing is fixed or removed.

What we publish

Every detail page carries a facts panel built from public data: repository stars, forks, license, and last activity for code; authentication and rate limits for APIs. Every panel shows the month we last checked it. Where a repository has been archived by its owner, the page says so in plain sight.

The MCP scorecard

Each MCP server is graded on five rows. The grades come from the same public data shown in the facts panel, using these rules and nothing else:

Maintenance. Strong when the repository saw a commit in the last 120 days, Fair within 365 days, Weak beyond that. An archived repository is always Weak.

Community adoption. Strong at 10,000 GitHub stars or more, Fair at 500 or more, Weak below 500. Stars measure popularity, not quality, which is why this is one row of five.

Setup effort. Strong when no account or API key is needed. Fair when it needs a free key or up to two environment variables. Weak when setup needs three or more.

License. Strong for a recognized open license (MIT, Apache-2.0, BSD, ISC, MPL-2.0). Fair when a different license applies or none is stated.

Listing freshness. Strong when we checked the listing within 45 days, Fair within 120 days, Weak beyond that.

The overall band follows the rows: Well kept means no Weak rows and at least three Strong ones. Handle with care means two or more Weak rows, or an archived repository. Everything else is Mixed signals.

Re-checks and corrections

Listings are re-verified on a rolling basis and the checked date on each page is the honest record of the last pass. Spot an error, a dead link, or a free tier that quietly became paid? Tell us through @hiddeninwest on X and we will fix the page or pull the listing.

Independence

Inclusion, ordering, and scores are never for sale, and no listing pays to be here. That is the whole business model: a catalog worth trusting, maintained by hand.
